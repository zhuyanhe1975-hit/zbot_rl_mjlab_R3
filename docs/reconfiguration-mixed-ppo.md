# 运动学状态机引导的混合角重构 PPO

任务：`Mjlab-Zbot-6dof-Reconfigure-Mixed-270-270-180-90-90-PPO`。

从全180°闭环开始，依次处理第1、2、4、5连接，得到五处内部注册角 `[270,270,180,90,90]`。第3连接及首尾辅助连接保持原180°。本任务的完成点仍是混合角闭环；不包含最后打开首尾及展开为爬行蛇。

## 控制分工

- 加载：从原生GPU物理数据读取当前质量矩阵、活动约束雅可比和柔度，批量解算力矩到六面载荷的局部响应；16个弯矩方向×两种拉力支持平面在GPU上做有界投影及安全缩放搜索。每次增量最多0.20Nm，加载前馈最多14Nm，目标递增3N。其他面预测缓冲56N，真实64N保护；目标面真实80N拉脱。无可行增量时保持或回撤以降低预测其他面峰值。该近似迭代优化不等同于旧CPU SLSQP，也不保证瞬态载荷。策略在加载阶段不参与动作或策略损失。
- 分离、旋转和接近：既有 `MixedClosedKinematics` 状态机生成四次重构的十二段关节轨迹，每段1秒、21个采样点；实际运动按当前物理阶段读取参考，不按离线时间强制换阶段。引导速度为参考速度加关节跟踪误差反馈，策略添加最大±2rad/s的速度修正；最终速度限±6rad/s、加速度限8rad/s²。
- 执行：速度积分成关节目标，使用MJLab原生位置PD；不将策略直接解释为力矩，不向物理仿真写入参考qpos或模块根位姿。
- 重连：端口位置、角度及相对速度满足条件并保持后才启用新注册weld；0.2秒柔度渐变、2秒安全保持，再切下一面。动作不直接开锁或重建weld。

已知运动学参考存在模块/地面穿透，它是软引导，不是无碰撞轨迹证明。策略可以偏离参考；2mm跨模块/打开端面穿透及3mm地面穿透保护仍保留。并行版为五个原来排除的端面增加显式碰撞对：各环境焊接时由模型专用GPU过滤器移除该对的CONSTRAINT标志，打开后保留该标志，产生真实接触力。过滤发生在窄相碰撞之后、约束构建之前，直接读取本步eq_active；保留SENSOR标志和全部普通碰撞。本机Warp的MULTICCD不能通过gap/margin充当开关，因此不采用该方案。适配器只标记新任务模型，不修改共享依赖文件；升级Warp后需要复核此私有接口。碰撞深度按contact.worldid在GPU归约，已移除逐环境CPU距离监测。

## PPO和观测

Actor/Critic均为172维：关节角、角速度、实际力矩、六面当前等效载荷与连接位、前馈/PD目标误差、物理阶段、目标面、端口相对位置/目标角差/相对速度、模块相对位置/速度/重力方向、引导速度、当前过滤后速度、策略修正、参考关节角误差、重建状态与阶段时间/进度。

六维动作仅在运动阶段影响控制。RSL PPO保留完整时序用于GAE和价值估计，策略损失、熵与KL只使用运动阶段样本。初始均值头为0，Gaussian标准差0.25。每轮128步，默认1000轮。

奖励包括全流程阶段/几何进度变化、完成奖励，以及 `penalty_safety_margin`、`penalty_failure`、`penalty_torque`、`penalty_time`。连续接近惩罚不能替代硬保护；14Nm以上每关节最多1秒、请求或实际力矩超过20Nm、其他面超安全阈值、异常穿透等均触发终止和训练复位。每次复位同时清除雅可比加载优化器的力矩和方向历史。

## 启动和限制

```bash
bash train.sh
bash run.sh
```

训练/回放日志根：`logs/rsl_rl_reconfigure_mixed_guided_batched_v4`。默认4096训练环境、1回放环境；可通过命令行调整。检查点控制模式为 `mixed_closed_batched_gpu_contact_filter_guided_motion_residual_v4`，拒绝旧单环境v2、旧碰撞开关v3及单面断开检查点。旧日志保留。

每个环境独立保存目标连接面、阶段、阶段时间、重连累计时间、新weld、引导采样进度、力矩优化历史及失败标志，可异步换面和选择性复位。运行时加载不再逐环境调用CPU MuJoCo/SciPy；GPU工作按512环境分块，当前仍有分块调度与约束行数上界读取的少量主机同步。运动学参考只在初始化时通过CPU生成并缓存。

修正碰撞过滤后的v4在本机RTX5090上实际完成4096环境×128控制步、一次PPO更新，524288条样本用时约26.35秒：采样26.15秒、学习0.203秒，约19894环境步/秒（非单环境实时速度）。该短测不是长期性能或重构成功验收；旧v3的gap开关实际没有关闭焊接端面接触，其训练不应沿用。未启动1000轮正式训练，未证明完整重构成功。

并行版验证证据：`outputs/reconfiguration/mixed_ppo/batched_validation_v4/` 及 `batched_4096_v4_smoke/`。91项有关测试通过，含异步阶段、各环境捕获和换面、选择性复位、显式碰撞对开关及GPU/CPU约束算子对照。无接触的同一焊接算子相对误差约5.73e-7；有接触时CPU/Warp接触集合可能不同，仍依赖实测闭环和物理保护。新检查点在64环境严格加载并回放80步，实际运动中局部复位未改动其他环境。参考轨迹已知不安全，短测仍有终止/复位，不宣称已学会全流程。
