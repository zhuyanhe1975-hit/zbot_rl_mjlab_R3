# 多教师蒸馏综合运动任务

任务 ID：`Mjlab-Zbot-6dof-Universal-Locomotion`。

本任务将双足运动、蛇形运动与双向变形放入同一个环境，由一个学生策略处理目标构型与三维速度指令。已有行走和双向变形模型作为冻结教师参与训练，最终回放只加载学生检查点。

这是新的训练任务和训练流程，尚不能把接口验证或短时 PPO 更新视为已经训练出全能策略。尤其蛇形推进、蛇形侧移及纯偏航缺少可靠教师，需要联合强化学习探索和单独验收。

## 开始训练与回放

```bash
./train.sh

# 先以较小环境数运行，检查设备容量和训练指标。
./scripts/python.sh train.py Mjlab-Zbot-6dof-Universal-Locomotion \
  --env.scene.num-envs 256 --agent.max-iterations 150

./scripts/python.sh play.py Mjlab-Zbot-6dof-Universal-Locomotion \
  --checkpoint-file /实际路径/model.pt --env.scene.num-envs 1
```

`./run.sh` 默认回放最新综合任务模型。两个 Shell 脚本直接列出各实验命令，通过注释手动选择；指定检查点可编辑 `run.sh` 当前命令，或使用上面的 Python 入口。务必显式传入综合任务检查点，旧双向模型的观测和动作接口不兼容。

默认训练 8192 个并行环境、3000 轮，每轮每环境采集 24 步，50 轮保存一次检查点。当前实现限于单卡、非循环 MLP；明确拒绝分布式训练、循环网络、混合精度、RND 和对称扩增。

## 统一任务接口

| 项目 | 定义 |
|---|---|
| 目标指令 | 构型：双足 `+1`／蛇形 `-1`；速度：`vx、vy、wz` |
| 阶段 | 双足运动、下降变形、蛇形运动、起立变形 |
| Actor 观测 | 50 维，包括六关节状态、六目标积分值、上一动作、运动状态、接触、构型、阶段、速度、步态相位／频率与初始航向误差 |
| Critic 观测 | 53 维，在 Actor 基础上增加质心状态和归一化接触峰值 |
| 动作 | 6 维独立 Beta 动作，范围 `[-1, 1]`，映射到六关节目标速度 |
| 目标速度上限 | 默认每关节 `2π rad/s`，积分目标受关节区间限制 |
| 物理模型 | 统一使用全身接触，允许蛇形低位接地 |

阶段由环境根据构型与保持条件更新，并非四个独立策略。切换构型时，速度指令平滑降至零；目标构型稳定后恢复保留的待执行速度。平移奖励跟踪整机质心速度，避免只摆动中部基座就获得前进分；偏航跟踪竖直角速度。失败另有一次性扣分。速度跟踪对三轴按各自上限归一化，按有效指令分量汇总推进奖励，并单独扣除非指令轴的漂移成本，以静止为零分基线；正常步态侧摆与基座摆转不会淹没真实推进收益。姿态势能的有符号进步奖励在构型到位后继续计算，避免阶段切换时突然少一项奖励。蛇形运动不要求六关节归零。Actor 包含基座竖直速度，能够区分教师使用的上升与下落状态。

前进方向沿用行走任务由重力与基座 Z 轴构造的水平轴；投影退化时沿用最近有效朝向。它不保证始终等于蛇身纵轴，测试和操作应按此坐标约定解释。步态时钟及初始航向条件同时提供给学生与教师，避免教师依赖学生不可见的条件。

训练按当前站／蛇目标数量补足各约一半名额，再随机分配速度，并混合双足／蛇形初态，防止短回合方向丢失训练数据。固定目标模式可设 `--env.commands.transform.mode stand` 或 `snake`，默认训练为 `source` 混合目标。速度课程分别记录双足／蛇形运动的真实跟踪表现 EMA，从上限的 20% 起步；表现达到 0.6 后逐步扩大范围，达到 0.85 时开放全部幅值，达到 0.75 后才采样多轴组合。此前只采样单轴指令；每次重采样有 25% 概率要求静止。预热不更新课程表现。变形超过 8 秒仍未到位将终止，自动重采样不能通过更换目标逃避该期限。综合任务不支持成功后自动反向，启用该选项会明确报错。训练保留失败终止及回合超时。手动回放不因普通跌倒、工作区越界或 45 秒超时自动复位，非有限状态仍会复位。

## 教师与适配

默认从本仓库 `bests/` 加载：

| 教师键 | 模型相对路径 | Actor 输入／输出 | 指导范围 |
|---|---|---|---|
| `walking` | `velocity_energy_disturbed_2026-10-10_iter499/model_499.pt` | 32／6 | 接近站立、以低偏航前向运动为主的状态 |
| `omni` | `omni_velocity_energy_2026-10-10_iter499/model_499.pt` | 33／6 | 接近站立的其他平移运动 |
| `transform` | `transform_snake_biped_bidirectional_2026-10-17_iter599/model_599.pt` | 37／3 | 镜像误差及目标区间可接受的变形和静止状态 |

三个教师保持冻结，读取同一学生环境，不额外创建教师仿真。适配器按旧配置重建观测顺序、裁剪、缩放及网络自身归一化；行走速度指令先通过世界坐标转换到教师坐标。仅在教师有效域内采集监督，纯偏航、明显偏离教师站姿和蛇形移动不强行模仿行走教师。

行走教师输出关节位置动作，学生输出目标速度。适配器先恢复绝对位置目标，再换算成当前控制周期可实现的限速目标变化。这是近似指导，不能精确重放旧位置控制步态。变形教师先对当前六关节目标做镜像投影，再积分三个教师动作并展开完整目标，最后按学生限速执行。这能逐步消除原有非镜像偏差，同时满足教师与学生的目标限制。

训练分为两个阶段，预热结束由能力验收决定，不能仅按轮数自动切换：

1. **教师带领的监督预热**：至少 100 轮，只更新 Actor。环境执行有效教师的确定动作，无教师覆盖时执行学生确定动作，采集前进、侧移、下降、起立四类场景。达到最低轮数但尚未通过门控时，约四分之一环境改为学生确定性执行，并继续查询教师纠偏标签，其余环境保留教师演示，补齐学生自身偏差附近的训练数据。运动预热示范最长 10 秒；变形到位且回合已持续 1.5 秒后重新开始示范，反复覆盖变形过程，避免大部分样本只是保持静止。起立示范随机覆盖 ±40 度侧滚。保留最近 8 轮有界监督缓存，覆盖完整步态和变形过程；缓存和优化按三个教师均衡分配。约五分之一监督样本永久标为留出数据，在缓存存续期间均不参与梯度更新。除动作均值误差外，还约束预热动作分布的随机性。
2. **学生自主 PPO 与辅助蒸馏**：预热达到最低轮数后，每 25 轮用独立的 16 环境进行 10 秒确定性学生评测。前进、侧移和双向变形各 4 环境，起立含 -20、0、20、40 度侧滚。各类至少 3/4 环境通过，且三个教师的留出样本覆盖、误差及动作标准差同时达标，连续通过 3 次才进入 PPO。放行时从刚通过独立验收的学生完整闭环轨迹中固定最多 4096 条基础状态（按前进、侧移及变形来源均衡，排除未通过的环境），并用已通过验收的学生策略生成确定性动作标签。联合阶段每个模仿批次一半取固定基础样本、一半取滚动教师数据；基础学生动作保持权重为 `100` 的独立均值保护，基础域动作方差也持续受约束，两者不随教师权重退火。这样保护的是已验收控制器，避免继续逼近教师标签反而改变其闭环行为。联合阶段始终执行学生随机动作，保持 PPO 的 on-policy 契约；模仿权重从实际放行轮数起，在 1000 轮内由 `1.0` 退火至 `0.02`。

评测统计最后 5 秒：构型至少九成时间到位，平移速度达到目标的一半以上且不过度超速，限制侧向滑移和无意转向，同时要求至少六成采样持续向正确方向运动；侧向和转向同时检查净偏移及绝对摆动量，防止冲刺、正负振荡抵消造成误通过。目标前进为 `0.08 m/s`、侧移为 `0.05 m/s`。没有评测回调或验收不合格时继续预热，不自动绕过。进入 PPO 后继续定期评测这些基础能力，日志可检查是否遗忘。该门控只验证教师已有的基础能力；蛇形平移、偏航、负向运动与组合控制仍须在 PPO 后另行验收。

预热当前轮及保留历史均没有有效教师样本时会明确报错；联合 PPO 只有在当前与历史都无有效样本时才跳过模仿更新。旧模型的 Critic、优化器和训练计数不作为新任务的初始化来源。

## 可调参数

以下参数已通过任务的 `--help` 核对，数值为默认值：

| 命令行参数 | 默认值 | 用途 |
|---|---:|---|
| `--agent.algorithm.distillation-enabled` | `True` | 是否加载教师并启用模仿 |
| `--agent.algorithm.warmup-iterations` | `100` | 最低监督预热轮数；设为 `0` 仍需通过能力门控 |
| `--agent.algorithm.anneal-iterations` | `1000` | 预热后的模仿退火轮数 |
| `--agent.algorithm.start-coef` | `1.0` | 起始模仿权重 |
| `--agent.algorithm.floor-coef` | `0.02` | 最低模仿权重 |
| `--agent.algorithm.distillation-batch-size` | `1024` | 模仿批次大小，至少 6 条以覆盖两类数据源和三教师 |
| `--agent.algorithm.distillation-max-samples` | `8192` | 每轮监督样本缓存上限 |
| `--agent.algorithm.distillation-updates` | `32` | 每轮模仿更新次数 |
| `--agent.algorithm.replay-iterations` | `8` | 保留最近监督 rollout 数，默认最多 65536 样本 |
| `--agent.algorithm.anchor-max-samples` | `4096` | 固定基础能力保护集上限，需至少 3 条 |
| `--agent.algorithm.anchor-coef` | `100.0` | 学生基础动作保护权重，保持恒定，不随教师项退火 |
| `--env.commands.transform.velocity-limits` | `0.25 0.20 0.8` | 前向／侧向速度与偏航速度上限，单位为 m/s、m/s、rad/s |
| `--env.commands.transform.transition-timeout-s` | `8` | 训练中变形到位期限 |
| `--agent.algorithm.validation-interval-iterations` | `25` | 最低预热后独立能力验收间隔 |
| `--agent.algorithm.validation-required-passes` | `3` | 放行 PPO 所需连续合格次数 |
| `--agent.algorithm.validation-min-samples` | `32` | 每教师最低留出样本数 |
| `--agent.algorithm.validation-max-mse` | `0.02` | 每教师留出动作均方误差上限 |
| `--agent.algorithm.validation-max-std` | `0.15` | 每教师留出动作标准差上限 |
| `--agent.algorithm.distillation-nll-coef` | `0.01` | 教师动作负对数似然辅助权重 |
| `--agent.algorithm.warmup-target-std` | `0.12` | 预热分布标准差约束目标 |
| `--env.commands.transform.hold-s` | `0.15` | 目标构型连续达标时间 |
| `--env.commands.transform.smoothing-s` | `0.25` | 速度平滑时间尺度 |
| `--env.commands.transform.gait-frequency` | `0.5` | 共享步态频率，允许 `0.25～1 Hz` |

纯 PPO 对照可使用 `--agent.algorithm.distillation-enabled False`，此时不需要教师文件。替换教师时，算法配置的 `teacher_checkpoints` 是以 `walking`、`omni`、`transform` 为键的路径字典，可只覆盖部分教师；CLI 用 `--agent.algorithm.teacher-checkpoints` 整体传入字典，不是逐个教师的点号子参数。具体字典输入格式以本机 `--help` 为准。Python 配置示例：

```python
from zbot_rl_mjlab.experiments.universal import UniversalLocomotion

cfg = UniversalLocomotion().build_ppo()
cfg.algorithm.teacher_checkpoints = {
    "walking": "/归档路径/model_499.pt",
    "omni": "/另一归档路径/model_499.pt",
    "transform": "/变形归档路径/model_599.pt",
}
```

相对教师路径按项目根目录解析。缺少文件或未知教师键会报错，不会静默退化为其他训练方式。

## 键盘控制

| 按键 | 操作 |
|---|---|
| `W`／`S` | 前向速度增加／减少 `0.05 m/s` |
| `A`／`D` | 左向速度增加／减少 `0.05 m/s` |
| `Q`／`E` | 偏航速度增加／减少 `0.1 rad/s` |
| `X` | 将待执行速度设为零，平滑停车 |
| `[`／`]` | 请求蛇形／双足构型 |
| `Enter` | 复位 |
| `Space` | 暂停／继续 |

这是按键增量控制，松开按键不会自动归零；需要主动按 `X` 停车。指令限制在配置速度范围内，操作影响回放中的全部环境。综合任务中的 `A` 被速度控制接管，不再触发原查看器的显示全部功能。

## 分模式训练指标

`phase_biped_fraction`、`phase_descending_fraction`、`phase_snake_fraction`、`phase_ascending_fraction` 分别记录四阶段交互占比。`biped_motion_normalized_velocity_error` 和 `snake_motion_normalized_velocity_error` 仅统计相应阶段存在非零运动请求的样本，用配置速度上限归一化质心平移和偏航误差。

没有有效样本时误差记为零，因此零误差本身不能证明技能成功，应结合阶段占比、教师覆盖以及实际运动验收。`warmup_student_fraction` 记录预热中实际执行学生动作的比例（含无教师处的回退）。教师日志分别记录 `candidates`（有效候选）、`cached`（缓存）和 `optimized`（实际梯度样本），不可混为一谈。`distillation_anchor_samples`、`distillation_anchor_optimized` 及各教师对应字段用于确认固定基础集确实参与训练。固定样本另有 `anchor_validation_mse`、`anchor_validation_std`，其标签来自已验收学生；普通 `validation_mse`、`validation_std` 仅衡量滚动教师标签，二者不能混为一谈。另有每教师留出误差、分布标准差、独立能力成功率、各项 `warmup_blocked_*`、连续合格次数、预热标记与模仿权重。奖励上涨不能代替这些能力指标。

## 保存、恢复与验证

正常检查点保存学生 Actor、Critic、优化器、训练轮数、实际 PPO 起点、门控进度、退火参数及速度课程 EMA，并记录教师键与 SHA-256。续训使用 MJLab 的 `--agent.resume True`、`--agent.load-run`、`--agent.load-checkpoint` 选项；保持相同任务和模型接口。`--agent.max-iterations` 在续训时表示本次额外执行的轮数。完整恢复时校验教师键及内容哈希，允许文件搬迁但不允许内容悄然改变。启用蒸馏的完整续训仍需对应教师文件。

大容量滚动回放缓存不写入检查点，恢复后从新交互重建；固定的小型基础保护集及轨迹来源随检查点保存和恢复。旧 50 维联合训练检查点若没有已验收学生来源的基础保护集，将重新接受预热门控，避免恢复后无保护地继续 PPO。显式仅加载兼容学生 Actor 属于热启动，会开启新的蒸馏进度并保留新环境课程；不能将旧分功能模型当作同接口学生直接完整恢复。回放和学生推理不会读取教师文件。

验收需分别统计双足／蛇形的前进、后退、纯侧移、纯转向、静止，以及两个方向的构型切换和连续混合指令。训练曲线还应观察教师覆盖比例、模仿损失和各模式回报。接口检查与短时 GPU 更新只证明运行路径可执行，收敛质量、长期稳定性和实机适用性需要后续训练评估。

修复前的 49／52 维综合检查点与当前 50／53 维观测不兼容，需重新训练；已有三个分功能教师保持使用。检查点维度不兼容时会明确报错，不能通过完整续训跳过新门控。

## 最终部署学生

任务 `Mjlab-Zbot-6dof-Universal-Locomotion-Deploy` 直接培养最终学生，不先训练一个全状态综合教师。默认使用原有三个冻结分功能教师；教师读取学生所在的同一个受扰物理环境，提供该状态下的动作指导。教师不会另跑干净场景，也不会在训练中更新权重。原综合任务的 50 维 Actor 保留不变。

学生单帧输入为 37 维，使用最近 5 帧历史，共 185 维：

| 输入 | 单帧维数 |
|---|---:|
| 关节编码器角度、速度 | 6 + 6 |
| 控制器内部目标、上次动作 | 6 + 6 |
| 机体系重力方向、角速度 | 3 + 3 |
| 用户目标构型、原始速度请求 | 1 + 3 |
| 软件步态时钟正弦、余弦与频率 | 3 |

Actor 不读取仿真真实线速度、高度、接触、构型阶段或依赖真值到位判定的有效速度指令。Critic 保留 53 维特权输入，仅参与训练。IMU 姿态、关节速度及软件时钟需在实际控制器中按相同约定提供。历史由 MJLab 观测管理器按“每项连续五帧，再拼下一项”的顺序展平，部署时必须保持一致。

物理随机化覆盖质量与惯量（约 ±15%）、PD 增益（原值的 0.7～1.3 倍）、机器人全身摩擦（0.3～1.2）及基座质心偏移（各轴 ±2.5、±2.5、±3 cm）。本实验暂不增加观测噪声、编码器零偏或控制延迟，避免与本轮物理抗扰目标混杂。

训练中约 25% 环境接受随机基座力与力矩；教师示范期使用全幅的 20%，进入 PPO 后按实际完成的 PPO 更新数，在 500 轮内升至全幅。全幅各分量范围为 ±5 N、±0.5 N·m，持续 0.08～0.20 秒，间隔 0.8～2 秒。域随机化从训练开始生效。能耗奖励及其余奖励继承综合任务，权重固定，不启用热改。

同一 Actor 先蒸馏，再继续 PPO，不在两个阶段更换观测或网络。有限观测无法完整重建教师特权状态，因此模仿 MSE 保留日志但不作为硬性放行条件；教师覆盖、动作标准差以及独立闭环能力仍必须通过。标称验收保留 185 维输入并移除随机化与外扰，用于原有连续三次能力门控。进入 PPO 后，每 100 次实际更新另做一次全受扰评测，全部评测环境接受外扰，结果使用 `robust_*` 字段单独记录。标称通过不等于抗扰通过。

从头训练：

```bash
./scripts/python.sh train.py Mjlab-Zbot-6dof-Universal-Locomotion-Deploy \
  --env.scene.num-envs 8192 --agent.max-iterations 3000
```

回放默认查找本实验目录内最新检查点，也可指定文件：

```bash
./scripts/python.sh play.py Mjlab-Zbot-6dof-Universal-Locomotion-Deploy \
  --env.scene.num-envs 1
```

日志目录为 `logs/rsl_rl/zbot_universal_locomotion_deploy/`。旧 50 维综合学生检查点不能直接恢复到这个 185 维学生；默认三个教师仍能使用原有归档权重。新学生之后可用相同任务配合 `--agent.resume True --agent.load-run 运行目录名 --agent.load-checkpoint model_轮数.pt` 完整续训，保留实际 PPO 进度及外扰课程。回放和导出只需要学生。上述入口均不要求修改 `train.sh` 或 `run.sh`。

接口回归和 GPU 阶段切换检查通过，不代表学生已经学会全部运动及变形。正式验收仍需覆盖蛇形运动、混合键盘指令、能耗和长期抗扰稳定性；目前的四项阶段门控仅覆盖双足前进、侧移及双向变形。

### 低速请求的教师适用域

行走教师仅在其可靠的速度范围内提供指导；速度小于该范围不代表用户请求静止。非变形阶段，变形教师只接受与静止奖励一致的 `requested_velocity.norm() < 0.01` 请求；其余没有可靠教师的小幅运动或转向交给 PPO，避免一边奖励推进、一边监督保持静止。真实变形期间仍保留变形教师指导。本修正不改变观测、动作、教师权重文件和奖励，因此可从同结构学生检查点保留优化器、已验收基础能力及 PPO 进度续训。

当前走势检查以双足运动、双向变形及抗扰为主。蛇形运动没有已有运动教师，暂不作为此次停训依据；四项基础验收通过也不代表所有双足指令幅值和方向已经掌握。独立多指令检查与监测记录保存在 `outputs/universal-deploy-monitor/`，属于本次运行的可再生产物。

### 带弯角蛇形先归直再起立

部署学生启用 `straighten_before_stand=True`。低位新起立请求的教师指导先把六个关节的实际角度和控制器积分目标都收敛到直线零位；两者最大绝对值均不超过 0.08 rad 后，才交给冻结起立教师。同一次起立只归直一次，不能在后续弯腿时再次触发；已经站立的机器人不会被要求拉直腿。取消起立请求或重置回合会正确更新这个教师侧状态。

这是训练中的组合指导，实际 rollout 仍执行学生网络采样的动作；学生回放不加载教师，也不在后台强制替学生执行归直动作。Actor/Critic 继续使用原来的 185/53 维接口，可以保留已有学生权重继续 PPO。教师的阶段记忆只用于生成监督标签，不能用“组合教师成功”代替“学生成功”的验收。

训练初态同时扩展：规范双足保持不变，约一半蛇形仍为标准直线，其余从独立生成的 32 个关节弯曲姿态中抽样，各关节不超过 ±0.2 rad，并叠加 ±40° 侧滚。每种姿态预先计算并缓存碰撞包络，重置时按地面净空放置，避免穿地。该增量仅在部署实验训练中生效，原综合任务保持默认关闭。

实际诊断中，32个相同轻弯角初态的12秒标称对照，旧学生成功24个，原冻结教师成功29个，先归直再起立的组合指导成功32个。这个结果只证明新指导可行；学生仍须独立复测弯曲初态，以及不复位的连续双向切换。未覆盖任意大弯曲、任意侧翻及实机状态。

为让学生明确区分“归直”和“起立”，部署指令使用现有构型标量的三个值：`-1` 蛇形、`0` 先归直、`+1` 起立/双足。用户起立意图在归直时仍然保持，软件阶段只由编码器角度、控制器内部目标及 IMU 重力方向计算；不读取仿真高度、足接触或构型到位真值。Actor 仍为 37×5=185 维，Critic仍为53维；原来两个构型值的含义保留，新增的零值需要补充训练。教师与学生读取同一软件阶段，阶段结束后不会因正常弯腿而再次归直。

本实验另增加固定权重 `-2` 的归直关节与目标平方成本，仅在软件归直阶段生效，退出后归零；其余原有奖励及能耗权重保持。它不会以强制执行动作替代学生控制。只增加教师侧隐藏归直阶段的早期试验未改善学生，因此未用于正式续训；学生补训与验收应使用带显式软件阶段的配置。

部署实验的独立能力门控已扩展到至少128环境，四项能力各32环境；起立组使用与训练随机姿态库不同的8个固定姿态×4个侧滚。新增 `ascent_pose_0_success` 至 `ascent_pose_7_success`、`ascent_bent_success`。除原四技能条件外，还要求弯曲起立总体至少90%、每种姿态至少75%，连续三次通过后才能进入PPO。原50维综合基线仍使用原16环境验收。

为学习新增的模式0指令，修正训练从原学生检查点保留Actor和Critic的全部网络张量，重新建立优化器并补充监督阶段；旧模型文件保持原样。早期两个直接续PPO的试验没有通过弯曲初态验收，未作为正式续训结果。新训练只有通过上述门控后才会重新转入PPO。原已执行PPO轮数与新阶段轮数分别记录，不能混作同一连续计数。

### 双足速度与方向课程

四个方向独立维护档位、连续通过和失败次数。前进档位为 `0.08、0.10、0.12、0.15、0.20 m/s`，后退、左移、右移各为 `0.05、0.075、0.10 m/s`。课程与原有整体速度跟踪 EMA 分开管理，避免 EMA 偏低时一直采不到目标速度。

约80%的非静止双足请求均匀分配给四个方向。每个方向一半样本取当前档位，四分之一取已经开放的档位，其余取连续中间速度。停车、转向、混合请求及变形调度仍保留。

进入PPO后，每25轮执行基础能力验收，再轮转检查一个方向。该方向成功率与全程不跌倒比例均至少90%、基础能力通过，且已有受扰起立成功率至少80%，连续三次后才升一档。尚未获得受扰结果时不升档，也不因缺少结果而降档。方向成功率低于60%或不跌倒比例低于90%，连续三次则该方向退一档；处于中间区间会清除连续计数。标称起立低于90%或已有受扰起立低于80%，连续三次则所有非零方向共同退一档。

方向验收模拟实际键盘切换：后退或侧移前先前进2秒、停车0.2秒，再以四种不同步态相位切换目标方向，全程保留真实观测历史。前进组先静止等待对应时刻。切换后继续运行10秒，用末5秒计分；防跌倒检查覆盖准备与运动全过程。速度误差、持续运动及侧向偏差等判据仍生效，测试只运行学生。

日志使用 `motion_course_forward_*`、`motion_course_backward_*`、`motion_course_left_*`、`motion_course_right_*`，分别记录档位、速度、成功率、不跌倒比例及连续计数。`motion_course_direction` 表示本次检查方向，`motion_course_rollback_reason` 为0无回退、1方向失败、2起立退化。没有出现的方向指标不能视为已经通过。

能力保护集按前进、后退、左右侧移、归直、起立、下降和其他状态分层抽样，防止短暂的归直阶段被大量稳定运动样本淹没。一半容量保留固定基础样本，另一半补充独立验收中成功环境的学生轨迹；旧标签保持不变，失败环境不进入保护集。检查点只保存合并后的张量与分界位置，避免重复存储。

检查点使用 `motion_speed_course` 第2版保存四向课程。旧版单前向课程首次迁移时，前进最多保留到0.10m/s，其他方向从0.05m/s开始，并清除连续计数；网络、优化器和已有保护集正常恢复。第2版检查点则精确恢复各方向进度。学生Actor/Critic仍为185/53维。

同一评测环境下，第1000轮模型的标称/受扰起立成功率为96.9%/90.6%，第1650轮为84.4%/65.6%，因此建议从第1000轮恢复，补齐后退和侧移，同时保护起立能力：

```bash
python train.py Mjlab-Zbot-6dof-Universal-Locomotion-Deploy \
  --agent.resume True \
  --agent.load-run 2026-10-18_13-23-48_speed_course \
  --agent.load-checkpoint model_1000.pt \
  --agent.run-name directional_course_v2 \
  --env.scene.num-envs 8192 \
  --agent.max-iterations 3000
```

这里3000表示本次额外迭代数。正式训练由使用者启动，无需修改 `train.sh` 或 `run.sh`。课程只控制训练采样，键盘能够请求某个速度不代表模型已经学会；短训验证也不能代替正式训练后的后退和侧移验收。当前验收暂不要求蛇形运动能力。
