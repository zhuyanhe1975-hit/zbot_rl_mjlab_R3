# 六模块参考路径动力学状态机

入口：

```bash
./scripts/python.sh scripts/reconfigure_mixed_closed_reference.py --viewer "$@"
```

目标：全180闭环逐面重构为 `[270,270,180,90,90]`；内部第3面和首尾连接保持原注册。该脚本不训练PPO，不改变现有PPO配置。

## 计算分工

- 断开前：GPU雅可比载荷响应优化关节力矩，使目标面达到80N被动断开；其他面64N停机保护。
- 断开后：参考七模块的分离、旋转、接近路径，逐步IK、碰撞/间隙筛查，C2关节样条与五次时间缩放，动力学执行。不继续使用载荷雅可比生成运动方向。
- 保留实际5cm分离目标；旋转按计划轨迹结束后接近，最终按实际2mm/2deg及速度条件捕获。新weld软建立，等待2s再推进下一面。

## v3 数值与执行修正

物理步长1ms，控制周期20ms。运动参考默认速度上限45deg/s、加速度上限180deg/s²。使用固定增益的MJLab原生位置PD（400/4），速度前馈通过位置目标偏置输入；删除额外的到位增益爬升。七模块原程序使用显式PID，当前六模块遵循用户此前要求，继续使用原生PD。

80N断开、其他面64N保护、14Nm持续/14～20Nm最多1s、超过20Nm保护保持。碰撞过滤仅豁免预期扣接端面（焊接、分离、接近阶段），旋转阶段启用当前打开面的接触，其他模块接触继续检查。该接触建模约定不等同于真实扣件的精确几何。

viewer在DONE或FAILED后自动暂停，避免停机后撤去位置保持、继续跌落引起的后续断开混入首个故障。可关闭窗口保存报告。故障提示区分其他面载荷保护、非目标weld失效、电机力矩及接触保护。

报告包含最近3秒物理步诊断（substep_diagnostics）：载荷、weld有效状态、接口力与力矩、关节/广义速度、电机实际/请求力矩。不得只用每0.5s的显示值判断瞬态峰值。

## 验证界限

四处离线路径已通过采样几何检查，不能替代真实动力学验证。5ms旧版第一面接近阶段出现速度起伏和10ms内25N→72N的载荷尖峰，触发64N停机时其余五weld仍有效。1ms低增益对照在49.9mm处分离超时，说明单独缩小步长不能解决轨迹跟踪。固定增益执行结果以保存报告和项目记忆的最新记录为准。
