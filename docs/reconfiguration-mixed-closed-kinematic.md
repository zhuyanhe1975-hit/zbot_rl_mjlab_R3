# 独立运动学重构：全180到270/270/180/90/90

实验标识：`Zbot-Closed180-To-270-270-180-90-90-Kinematic-v1`。

```bash
bash run.sh                         # 默认窗口演示
bash run.sh --headless              # 无窗口规划并保存报告
bash run.sh --headless --order 1 2 4 5 --output outputs/reconfiguration/mixed_closed_kinematic/manual.json
```

`run.sh`第27项为当前入口，第26项原RZ270运动学实验及更早动力学实验保留为注释。直接脚本为`scripts/reconfigure_mixed_closed_kinematic.py`，不读取检查点、不创建PPO、不运行动力学。

初态五个内部安装角全部180°，首尾辅助连接也保持原180°注册。顺序为第1、2、4、5连接，每处执行断开→分开5cm→旋转安装注册角90°→接近→重建weld。第1/2处180→270，第4/5处180→90。第3连接不拆、不改安装角，但不锁定第三电机关节；六个电机关节均允许参与整链FK/IK。

每次只断开一处，另外五条连接形成完整连通链；重连后恢复六面闭环。首尾辅助连接始终不打开、不换注册角，最终仍闭环，不再展开为关节零位。每帧检查连通性，禁止两个断口、独立移动模块/链段、同时激活同面两个注册weld。所有自由根位姿只由一个锚定根和整链关节FK派生。

默认每段名义1秒、20采样帧，四处共12秒。关节限位、力矩、载荷、动力学、碰撞和电机速度可行性均忽略。窗口仅播放预先计算的运动学轨迹，空格暂停、Enter重播，完成后停留终态。IK失败时停在最后有效连通姿态并显示IK_FAILED，不跳过或强行重连。

默认20点方案已完成从初始到目标的无窗口运动学验证，六面有效weld均通过独立MuJoCo FK核对。IK分支对采样/顺序敏感：50点试验曾在最后一次接近、近奇异折叠位置不收敛，报告保留`verification_50samples_failed.json`；不承诺任意采样或顺序都能走通。未检查自碰撞或动力学可执行性。

报告默认`outputs/reconfiguration/mixed_closed_kinematic/latest.json`，包含目标与实际五角、处理顺序、每段误差、重连事件、有效weld几何检查和全程连通性。完整默认入口验证保存在同目录`verification.json`。成功退出0，失败返回1。不会覆盖原状态机报告或训练日志。
