# 全流程状态机打磨

```bash
./polish_mjbatch.sh
./polish_mjbatch.sh --count 16 --batch-count 64 --threads 20 --workers 2
```

脚本读取最近一次已验证的 `run_planned_mjbatch.sh` 结果，也可通过 `--result` 指定。它用 mjbatch C++ 线程池先批量筛选首尾卷曲候选，然后在独立进程中从固定初态并行执行完整状态机。候选除卷曲路径外还调整内部接口目标速度、第4接口对齐阶段法向目标和历史展开控制的时间缩放；候选从通过严格首尾筛选的两个运动学分支中抽取。只有完整执行成功的候选才按总仿真时间排序。

每次运行建立 `outputs/reconfiguration/full_polish/时间戳/`，`search.json` 包含全部候选的各阶段时长、非目标载荷峰值、电机力矩峰值、模块与地面接触深度、法向检查统计及失败原因。`validation_N.json` 和 `candidate_N.log` 是各自完整记录；`result.json` 是最短的已通过候选。载荷、力矩、数值异常、MuJoCo warning 和原状态机接触深度保护在整个执行中启用。

```bash
./view_planned_mjbatch.sh  # 最近一次 run 或 polish
./view_planned_mjbatch.sh --result outputs/reconfiguration/full_polish/某次运行目录
```

检查范围：site 法向负距离只在 CURL、CAPTURE_HEADTAIL 和 APPROACH 阶段、site 距离不超过30mm时以1ms检查；它不是完整几何碰撞检测，也不能保证子步间连续安全。完整流程仿真使用精修查看器的单世界 MuJoCo，进程级并行而非 mjbatch.Batch；只有 CURL 搜索用 mjbatch C++ 线程池。其他阶段是参数搜索并复用原控制器，展开通过缩放历史控制序列探索，非从零生成完整最优轨迹。原先轨迹加速度参数仍然存在。结果基于固定初态，不代表扰动或实物安全。

## 严格筛选（当前默认）

排序优先级为：先拒绝模块几何接触/侵入，再拒绝载荷、力矩、速度等超限，最后按完整仿真时间选择。全部跨模块碰撞几何每1ms用 MuJoCo `mj_geomDistance` 检查，允许已焊接接口的配对接触面，以及 site 已达到1mm/2°对齐阈值的配对接触面；机器人与地面的支撑接触允许，仍受原3mm地面侵入保护。实际关节速度限值使用此前的2π rad/s，作用于全流程；实际关节力矩20Nm、持续14Nm、非目标载荷80N及原异常保护仍启用。没有新增加速度限制。

这是离散1ms采样且网格碰撞依据MuJoCo凸几何，无法证明子步间或实物无碰撞；焊接后配对几何与地面支撑是明确允许的接触。当前模型的6个关节动力学未启用位置限位；新polish额外检查源XML中的±6.28 rad范围，但该范围尚未独立验证为实物硬限。默认搜索为32个全流程候选、每分支256个CURL候选，允许较长执行；没有合格候选时输出失败，不选最快的违规候选。

当前版本先对两个首尾运动学分支分别运行带几何碰撞和实际关节速度保护的 mjbatch CURL 筛选，然后均匀抽样进入完整流程验证。捕获阶段没有经过验证的无碰撞闭合规划器；如果所有候选在对齐前发生首尾接触，仍会无合格结果并输出分类统计。`--branches 1` 可只搜索原分支。

首尾闭合先求沿目标site Z轴留出30mm的预对齐关节构型，再把局部XY及三个姿态误差纳入实时雅可比修正；进入Z接近阶段要求XY<0.2mm、姿态误差<0.5°。之后每1ms根据50ms动力学预测，将五维误差目标按 `exp(-6*0.05)` 缩小，同时推进Z；偏差过大时暂停Z并继续修正五维，距目标小于5mm时使用更严格门控。这是指数误差目标和离散闭环控制，不保证实际误差严格指数下降。对接容差内（site总距离<1mm、姿态<2°）只允许目标接口配对几何接触；旧连接在释放后仍在原配对位姿容差内时亦允许该配对接触，其余碰撞仍拒绝。

新结果首尾反馈采用四个对应点及 `mj_jacSite`，并结合真实位置伺服的动力学预测；四点用于表达目标方位和位姿误差，不产生磁力，也不能代替几何碰撞检查。`--landmark-radius-mm` 可设置引导点半径（默认50mm，只是虚拟参数，尚未依据实物标定）；设置写入结果并用于回放。现有 site weld、容差、断裂判据及其中心参考仍在使用，旧结果沿用原控制方式。四点与磁铁的物理建模边界见 [magnetic-docking-model.md](magnetic-docking-model.md)。

固定初态12候选试验中，1个完成首尾捕获，后续内部接口释放产生容差外的模块接触而失败；其余11个首尾接近时发生容差外接触，尚无完整通过方案。

## 内部释放诊断

```bash
./analyze_release_mjbatch.sh --count 4096 --threads 20
```

诊断从一次已通过首尾捕获的候选恢复完整状态，在第1内部接口释放子步保存物理状态，批量检查该状态附近的恒定关节位置命令。`--search-dir` 和 `--candidate` 可指定含完整候选信息的搜索目录。输出在 `outputs/reconfiguration/release_analysis/`；`analysis.json` 中状态码6表示模块几何接触，1表示非目标载荷超限。它是局部控制采样，不生成完整规划，也不证明全局无解。

当前 polish 的物理步、控制更新、状态机判断、几何和安全采样均为1ms；50ms是预测滚动长度，不是采样周期。旧20ms结果的重放仍保留原周期。1ms不是对所有可能动作穷举，也不保证一定找到可行解。

当前 polish 在每个内部 `SEPARATE` 物理步启用预测采样 MPC：从当前完整积分状态使用严格 mjbatch C++ 线程池预测候选，默认每1ms重新选择、1024个位置命令候选、20ms前瞻；预测碰撞/载荷/力矩/速度不合格的候选淘汰，无安全候选则停止。每次完整验证报告记录调用次数、无安全候选次数及一次批量与串行状态误差。可用 `--mpc-candidates`、`--mpc-horizon-ms`、`--mpc-threads` 调整。该预测在内部分离、旋转、接近阶段启用，断开前加载和首尾对接仍是原控制，不是全流程MPC；短视滚动预测不能保证递归可行或连续无碰撞。

预测除逐1ms拒绝几何接触外，还记录不属于容差内配对面的各模块凸网格最近距离（最大测距50mm），默认要求预测最小距离至少0.5mm并参与评分，可用 `--mpc-distance-margin-mm` 指定。新polish在原始约束力计算后刷新积分后的几何位姿，避免混用下一状态与上一求解步；对源XML的±6.28rad也做审计。碰撞几何使用MuJoCo凸包，仍不是原非凸STL精确表面。当前未找到完整合规方案。
