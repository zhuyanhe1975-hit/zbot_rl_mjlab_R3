# 离散闭环注册状态检查：180→90 / 180→270

只检查静态几何闭合，六处连接全部闭合，关节限位、碰撞、力矩和动力学均忽略。不把某条连续IK轨迹是否走通当作离散状态是否存在解。

```bash
./scripts/python.sh scripts/verify_closed_registration_states.py --target-angle 90 --refine-starts 512 --max-nfev 300
./scripts/python.sh scripts/verify_closed_registration_states.py --target-angle 270 --refine-starts 512 --max-nfev 300
```

连接0–4是内部连接，5是首尾辅助边。枚举六条连接各保持180或改成目标角的全部64种状态。闭合判据为位置≤1微米、角度≤1e-5rad。找到的解逐个用独立MuJoCo FK核对全部六条有效weld。没有找到解的状态各用512初值，包括相邻已解状态、原初态、零关节与随机初值。求解器无关节上下界；保存的关节角仅按2π周期规范显示。

| 改成目标角的连接数 | 180→90 找到/总数 | 180→270 找到/总数 |
|---:|---:|---:|
| 0 | 1/1 | 1/1 |
| 1 | 6/6 | 6/6 |
| 2 | 15/15 | 15/15 |
| 3 | 20/20 | 20/20 |
| 4 | 15/15 | 15/15 |
| 5 | 0/6 | 0/6 |
| 6 | 1/1 | 1/1 |

两种方向都是58状态找到解、6状态未找到。未找到的正好都是“5处目标角+1处180”。如果首尾保持180，按0→1→2→3→4处理内部连接，前四步都有解，最后一步未找到。如果首尾先改成目标角，处理第4个内部连接时就进入同类瓶颈；内部五处和首尾全部改完的静态终态本身有解。

这意味着仅换处理顺序，在当前已验证节点组成的图里也避不开5+1这一层；不是所有早期IK失败都属于这个瓶颈，例如3处已替换的每个离散状态均已找到解，之前某些失败只是所走IK分支未收敛。

**未找到不等于已严格证明无解。** 此检查没有做全局区间证明，也没有验证各静态解之间的连续可达性、避碰或力可行性。最佳候选的位置/角度残差是当前加权目标下的数值结果，不能当作误差的数学下界。

结果：`outputs/reconfiguration/discrete_closure_comparison.md`，两种目标角各目录中的`report.json`保存64种状态的解/候选和独立核对误差，`states.csv`便于查看。8项相关CPU测试通过，覆盖两种方向的解析Jacobian与独立有限差分、统一角状态的MuJoCo闭合验证、未找到状态的诚实标记，以及原连通性/目标模型检查。未修改run.sh或当前状态机。


## 2026-10-28：交替270/90

按用户1–6编号，目标为`[270,90,270,90,270,90]`。同样枚举64种离散状态，63种找到严格闭合解；未找到的仅全目标角末态。首尾第6面保持180时，前五面逐一交替替换的每个离散闭环都存在经MuJoCo核对的解，因此与统一90/270的5+1瓶颈不同。

最终全交替状态512初值＋128次LM精修，最佳候选的独立MuJoCo位置误差约1.59e-7m、角误差约.037637°，未通过1e-5rad角阈值。六个关节接近±π，Jacobian最小奇异值约2.16e-9，属于接近奇异的折叠候选。未找到严格解不等于已证明无解，也尚未验证碰撞或连续路径。

若首尾辅助连接最终只需打开，则静态候选路线可以先完成`[270,90,270,90,270,180]`再打开首尾，不必先强求全交替闭环。没有自动修改状态机，连续重构仍需另验。结果位于`outputs/reconfiguration/discrete_closure_alternating_270_90/{report.json,states.csv,summary.md}`。

## 五个内部安装角与首尾辅助边的区别

六个模块只有五处内部安装方位角，另有六个可动电机关节。首尾闭环辅助边是额外的边，不是第六个内部安装角。上述64状态枚举把“五个内部角＋一个首尾注册条件”一起枚举，不能把特定首尾条件下的失败误读成五角目标构型本身不存在。

静态结果：五个全90、五个全270、270/90交错（两种起始方向）都能定义连通开链目标，六关节零位的独立MuJoCo FK均验证五条安装连接吻合。若要求额外闭环，五个全90配首尾90、五个全270配首尾270均有已验证解；两种五角交错配首尾180也有已验证解。首尾保持180时，五个全90/全270的512初值搜索未找到解，只针对这一附加闭合条件。

上述是静态目标，不证明能从五个180沿着逐面拆装、始终连通的连续路径到达。开链目标证据`outputs/reconfiguration/five_internal_angle_targets.json`；反向交错闭环证据`outputs/reconfiguration/discrete_closure_alternating_270_90/reverse_five_face.json`。
