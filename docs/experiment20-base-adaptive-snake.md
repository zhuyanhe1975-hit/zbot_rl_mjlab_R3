## base参考与回放

仅本实验的spec添加base_motion参考点，共用XML不改动，质量、惯量、摩擦和执行器不改变。vx/vy测量base刚体原点速度并投影到随base转动的重力对齐坐标；wz测量base绕世界竖直轴的角速度。初始前进方向与原foot_0一致，观测布局仍为61维。

速度、重力/倾角参考及评测均使用base。这里是中央刚体原点，不是整机COM，仍应独立检查质心净位移。

Play绘图原点为base世界Z方向上方0.1m。平移指令蓝色、实测绿色，yaw指令橙色、实测紫色。文字保留Requested和Actual。绘图偏移不改变实际跟踪位置。

## 速度奖励恢复[-2,1]

有运动指令的轴：

`r_i = clamp(1 - 2*abs(c_i-v_i)/abs(c_i), -2, 1)`

实际速度为指令的0%/50%/100%时分别得−1/0/1；150%得0，200%得−1，更大误差最多扣至−2。正负方向对称。

指令绝对值≤1e−6按停车处理：`clamp(-abs(v_i)/L_i,-2,1)`，静止为0，漂移扣分。std参数不再参与此配方。三轴自适应调权，高斯策略、动作积分、其他奖励及关节目标配置保留。

## 两阶段调权

奖励仍为[-2,1]，在RewardManager计算后、自动reset前采集实际带符号的加权奖励，除以本轮权重，以0.05 EMA平滑。正分与负分不按绝对值混合。

第一阶段优先平动：初始权重为`B*(0.475,0.475,0.05)`，旋转占总速度奖励预算的5%，平动内部按跟踪能力EMA提高弱项权重；各方向占平动预算25%—75%。不通过正负分比例来分配预算。

切换条件：vx/vy本轮运动指令有效样本各至少128个，运动指令下的跟踪分EMA与包含停车漂移惩罚的实际奖励EMA均超过0.02，且本轮运动指令分均为正；连续20个PPO更新满足后进入第二阶段。缺少覆盖、近零奖励或任一平动方向未达标会清零连续计数。这样避免平动合计正分掩盖其中一轴未学会。

第二阶段加速旋转：wz原始奖励EMA未超过0.02时，将其预算目标提高至40%，以0.05系数平滑靠近，强化旋转学习信号。平动仍共享剩余预算。旋转转正后恢复收益目标：

`Rvx ≈ Rvy`，`Rwz ≈ (Rvx+Rvy)/4`。

平动正收益时，令`px=my/(mx+my)`、`py=1-px`，px限制在25%—75%；其他情况保持平动内部占比。令`mplan=px*mx+py*my`，旋转正收益时目标预算`z=mplan/(4*mz+mplan)`，限制在0.1%—60%。预算B不变，权重每轮以0.05平滑。涉及负分时不取绝对值来拟合收益比例。

若第二阶段任一平动方向的运动分EMA或实际奖励EMA低于-0.02，并在具有双轴覆盖的更新中连续10轮成立，则退回第一阶段。全停止或无有效样本时不推进阶段。

控制台显示当前阶段、转正连续计数和退化连续计数，以及vx/vy和旋转/平动的实际正收益比例。权重边界、平滑与训练过程使比例只能近似；两阶段机制也不能保证训练收敛。
