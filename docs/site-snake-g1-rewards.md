# 蛇全向任务：速度跟踪、软限位与 site 倾角奖励 v5

适用任务：`Mjlab-Zbot-6dof-Snake-Site-Omni-Teacher`。
采用 G1 的指数跟踪形式，数值尺度按本项目 Zbot `bests` 重新定标。
奖励由两项速度跟踪、两项软限位惩罚和一项 site 倾角惩罚组成。

| 分项 | 权重 | 定义 |
|---|---:|---|
| track_linear_velocity | +4 | `exp(-sum((v_xy-c_xy)^2)/σv²)`，`σv=min(.1, .02+.5*norm(c_xy)) m/s` |
| track_angular_velocity | +1 | `exp(-((w_z-c_wz)/σw)²)`，`σw=.25 rad/s`，平移、转向、停止均相同 |
| joint_pos_limits | −1 | `sum(max(abs(q)-.9*L, 0))`，实际关节角超出软限位的弧度和 |
| joint_target_limits | −1 | `sum(max(abs(q_target)-.9*L, 0))`，积分目标角超出软限位的弧度和 |
| site_tilt | −1 | `1-cos(θ)`，θ 为 foot_0_sole 标准朝上轴相对反重力方向的夹角 |

`v_xy` 为 **foot_0_sole site 的真实线速度**在 site 重力对齐平面内的投影，
不使用整机质心速度；水平前向为 site 的 −Z，侧向为左方。
`w_z` 为该 site 绕世界竖直轴的实际角速度。不锁定世界 X 或初始朝向。
线速度核保留低速分辨率并在归档的 0.1 m/s 宽度处封顶；角速度核使用归档 Zbot 的 0.25 rad/s 宽度。

速度跟踪在所有指令下启用：纯转向时线速度目标为零，停止时线速度和角速度目标均为零。
没有额外的停止姿态奖励、alive、竖直速度、能耗、动作平滑或失败扣分。
每步总奖励为 `(4*r_linear + r_angular - cost_actual_limit - cost_target_limit - cost_site_tilt)*step_dt`。

软限位参照 G1 的超限弧度求和形式，但采用 Zbot 当前蛇形动作的角度范围，
`L=π/3`（60°），90% 处即 ±54° 开始连续扣分，范围内为零，不要求关节保持零角度。
目标角仍在 ±60° 截断，目标角速度仍为 `2π rad/s`（360°/s）；这是目标积分速度上限，
不是对仿真实际关节速度的硬截断。
实际角和积分目标角分别计费，防止实际角尚未跟到边界时，目标就一直钉在硬限位上。
六个实际角和目标角全部停在 ±60° 时，合计惩罚约 −1.2566/秒；目标退回 ±54° 内即取消目标部分。
此改动产生离开限位的奖励信号，不保证已停滞策略无需重新探索就能恢复运动。

奖励、观测中的 tracking velocity、速度误差指标和独立评测使用同一个 site 速度入口。
其余既有特权物理观测保持原样，未改变 56 维布局。
已归档任务的奖励与质心速度参考不变。

训练保留 `self_collision` 和 `site_tilt` 两个终止重置条件，不额外收取一次性失败费用。
site 倾角超过 60° 时触发 reset；恰好 60° 不触发，使用 1e-6 rad 浮点容差。
unsafe 和 time_out 仍不触发 reset。初始 reset 和用户主动 reset 仍可使用。
回放不自动重置。30 秒 episode 配置仅保留作框架统计配置，不再触发时间终止。

倾角使用 site 的实际四元数，不读取 foot_0 body 四元数。
蛇形规范姿态的 site +X 是朝上轴，将其与配置的重力反方向比较；重力先归一化，
因此重力大小和绕重力轴的 yaw 转动不会改变倾角惩罚。
0° 时惩罚为零，30° 时约 −0.134/秒，60° 时 −0.5/秒。
独立评测的倾角判据同步使用该 site 和相同 60° 阈值，不自动重置。

检查点标记 `snake_omni_version=3`、`tracking_point=foot_0_sole`、
`reward_recipe=zbot_snake_velocity_limits_tilt_v5`，评测协议为 `site_snake_omni_v3`。
旧 COM 参考或其他奖励配方的检查点不作为本版兼容检查点加载，需从头训练。
训练和回放脚本保持用户指定的简洁参数形式。

验证覆盖前后/侧向/组合速度、低速和高速、反向、超速、侧滑、转向、停止、
site 与 COM 不一致时的参考点选择、旧任务参考点不变以及自碰撞/超过 60° 的 site 倾斜重置。
CUDA 冒烟检查 32 个环境、96 步仿真与 3 次 PPO 更新，检查观测、奖励和模型参数有限。
此验证不代表完成 600 轮训练或证明策略收敛。

## 范围与归档依据

| 设置 | 新值 |
|---|---|
| 前后、侧向指令上限 | 每轴 ±0.2 m/s |
| yaw 指令上限 | ±0.5 rad/s |
| 纯平移非零指令幅值 | 0.08–0.2 m/s |
| 纯转向非零指令幅值 | 0.2–0.5 rad/s |
| 混合指令 | 各轴分别在上限内连续采样，可接近零 |
| 重采样间隔 | 5–9 秒 |
| 可选手动前进速度档位 | 0.08 / 0.10 / 0.12 / 0.15 / 0.20 m/s |
| 独立评测两档（平移，yaw） | (0.08 m/s, 0.2 rad/s)、(0.15 m/s, 0.5 rad/s) |

采样仍覆盖停止、六个有符号单轴及混合运动；不按 tracking EMA 缩小范围。
纯指令的最小幅值是对应上限的 40%；停止另行采样。手动指令也使用相同限幅。
前进档位沿用已有部署命令配置，当前特权训练采用连续采样，不按这些档位运行课程。

- [蛇模型说明](../bests/snake_world_x_2026-10-19_iter1499/README.md)、
  [独立回放](../bests/snake_world_x_2026-10-19_iter1499/verification.json)：
  原世界 X 推进奖励在 0.2 m/s 封顶，训练平均约 0.150 m/s，独立回放平均约 0.083 m/s。
  用它们选择 0.08 的纯指令下限和 0.2 的平移上限；这些旧数据是质心世界速度，
  不宣称新任务的 foot_0_sole site 已验证达到同样速度。
- [Zbot 全向行走配置](../bests/omni_velocity_energy_2026-10-10_iter499/env.yaml)：
  原指令范围 vx=[−0.3,0.5]、vy=[−0.2,0.2] m/s、yaw=[−0.5,0.5] rad/s；
  平移奖励 std=0.1 m/s，yaw std=0.25 rad/s。蛇任务不照搬更快的双足前进范围。
  侧向和 yaw 的范围据此作为新训练目标，不作为蛇已有能力结论。
- 归档蛇配置中的 ±0.25 m/s、±π/2 rad/s 当时对应 `sample_velocity_commands=false`，
  不能当作已验证的全向跟踪范围。已归档行走模型的纯 yaw 表现也较弱。
- 直接使用固定 0.1 m/s 的线速度核，低速指令下静止得分偏高；因此采用随指令增长、
  上限为 0.1 的宽度。0.08 m/s 指令时 std=0.06，0.2 m/s 时 std=0.1。
  指数里的 std 是误差容差，不是策略动作分布的标准差。

139 项相关测试、Ruff、Pyright 和 32 环境 CUDA 下 3 次 PPO 更新通过。
这些设置仍需完整训练验证，未宣称后退、侧移和转向已收敛。

## 训练显示

默认沿用 G1 / rsl_rl 的迭代标题和逐项对齐样式，终端仅显示：

- `Mean reward rate (/s)`：本轮总奖励率。
- `Reward/track_linear_velocity (/s)`：本轮线速度跟踪的加权贡献。
- `Reward/track_angular_velocity (/s)`：本轮角速度跟踪的加权贡献。
- `Reward/joint_pos_limits (/s)`：实际关节软限位惩罚。
- `Reward/joint_target_limits (/s)`：积分目标软限位惩罚。
- `Reward/site_tilt (/s)`：site 相对重力的倾角惩罚。

以上统计取本轮所有环境和时间步的平均值，不等待回合结束。
原生日志写入器仍保存全部损失、性能和回合统计；终端隐藏这些非奖励项。
训练日志只改变呈现方式，不修改 PPO、奖励函数或 reset 条件。

默认关闭定期评测和鲁棒性评测，不在第 100/500 轮生成评测报告；模型保存保持启用。

本次归档以 `2026-10-20_19-07-44/params/env.yaml` 为准：线速度权重 4、site 倾角权重 −1；这两项是实际训练配置。
