# RZ270 独立蛇形实验

任务：`Mjlab-Zbot-6dof-Snake-RZ270-Teacher`。参数入口：[实验卡片](../src/zbot_rl_mjlab/experiments/cards/snake_rz270_teacher.json)。

## 构型与初态

以零关节角的直立柱为安装参考，六个模块之间的五处固定连接（`a2`、`a3`、`base/a4`、`a5`、`a6`）均采用相邻模块局部 `RZ=270°`，替代原来的 `180°`。这是固定安装变换，不是电机关节转到 270°；六个电机关节的零位、轴定义、限位、惯量和执行器参数不变。

原连接旋转为 `Ry(-45°) Rz(180°)`，新连接在其右侧乘 `Rz(90°)`，得到 `Ry(-45°) Rz(270°)`。保留 CAD 原始平移与四元数精度，由独立 `rz270_spec()` 构造，仅本实验使用，原 XML 和其他任务保持原构型。

**训练和回放每次重置均趴地，蛇头朝世界 +X**，不随机初始航向。根部相对各环境原点的位置为 `(0, 0, 0.0555)` m，四元数为 `(√0.5, 0, -√0.5, 0)`（wxyz），六个关节为零，初速度为零。头部为 `foot_0`，其 site 的 `-Z` 朝向世界 `+X`，尾部沿 `-X` 延伸。网格最低点离地约 3 mm，供重力落地；不是站立启动。初始身体方向保持 +X；目标航向独立采样，随后由策略转向，不直接旋转机器人。

## 训练与回放

```bash
./scripts/python.sh train.py Mjlab-Zbot-6dof-Snake-RZ270-Teacher \
  --env.scene.num-envs 8192 --agent.max-iterations 6000

# 新任务独立日志目录中的最新模型：
./scripts/python.sh play.py Mjlab-Zbot-6dof-Snake-RZ270-Teacher \
  --env.scene.num-envs 1
```

日志默认在 `logs/rsl_rl/zbot_snake_rz270_teacher/`。`train.sh`、`run.sh` 末尾新增第 23 项注释示例，不自动启动正式训练。

使用 63 维观测（原 site 状态 61 维，加目标航向误差的 sin/cos）、6 维积分目标角速度动作和 Gaussian PPO。默认 8192 环境、6000 轮，目标角范围 ±120°。卡片继承 site 参数并显式替换奖励，不启用自适应调权。

新检查点包含构型、航向采样与奖励版本标识。旧三轴速度跟踪检查点与当前 63 维观测不兼容，需要从头训练。回放恢复检查点的航向采样范围和前进速度奖励上限。

## 卡片中的奖励和限制

卡片 `rewards` 显式列出全部 10 项奖励。原 `track_forward_velocity`、`track_lateral_velocity`、`track_angular_velocity` 已移除，改为：

| 奖励 | 计算 | 权重 |
|---|---|---|
| `head_forward_speed` | 蛇头 site 前向速度相对前行指令的线性符合度，准确跟踪为1、反向为负、超速后线性衰减；原始分数[-1,1] | 4 |
| `heading_alignment` | `−abs(wrap(目标世界航向 − 当前蛇头航向))`，单位rad；对齐0、垂直−π/2、反向−π | 1 |
| `site_tilt` | 蛇头 site 局部 +X（向上轴）相对反重力方向的夹角平方 `θ²`，单位 rad² | -1 |
| `head_lateral_speed` | 蛇头 site 线速度在当前蛇头水平左右轴上的投影绝对值 `abs(v_left)`，单位 m/s | -5 |

当前速度奖励使用蛇头 **site** 前向实际速度 v 和未滤波前行指令 u，均可在63维策略观测中读取。u>0 时原始得分为 `clip(1−|v−u|/u, −1, 1)`；u=0 时为 `clip(1−|v|/stop_speed_scale, −1, 1)`，默认 `stop_speed_scale=0.05 m/s`。权重仍为4，因此速度奖励率范围为[-4,4]，0.02秒控制周期对应单步[-0.08,0.08]。航向项改为绝对角度偏差惩罚 `−|θ|`，θ为[-π,π]内的最短有符号航向差；权重仍为1，奖励率范围[-π,0]。零点附近呈线性响应，误差1°约−0.01745、5°约−0.08727，不设死区。原有 `site_tilt` 从 `1−cosθ` 改成 `θ²`，只计一项倾斜罚，不重复叠加。横向惩罚左右对称，不惩罚纯前行或竖直速度，也不直接惩罚偏航角速度。其余存活、动作变化、姿态、角度边界和失败扣分保留。

例：倾斜 30° 时倾斜奖励约为 −0.274；横向速度 ±0.1 m/s 时横向奖励为 −0.5（均为按时间缩放前的奖励率）。任务卡可分别调整两个权重。60° 倾斜终止边界保持原样；增加 `head_tilt_rad` 和 `head_lateral_speed_m_s` 指标。观测仍为 63 维，动作与控制参数不变，可从现有采样航向版检查点继续训练。

`env.commands.transform` 中：

- `heading_range=[-π, π]`：均匀采样目标世界航向角，0 朝 +X、π/2 朝 +Y。
- `resampling_time_range=[15, 15]`：训练与回放每 15 秒共同重新采样前行速度和航向。
- `forward_speed_cap=0.2`：手动前行速度指令的上限及速度箭头归一化尺度，单位 m/s；不再截断实际速度奖励。
- `forward_speed_range=[0, 0.2]`：非停车指令的均匀前行速度采样范围，单位 m/s。
- `forward_stop_probability=0.1`：额外以10%概率采样精确停车指令 u=0。
- `play_forward_speed=null`：回放也采样前行速度；设为具体值（0～forward_speed_cap）可固定回放速度，键盘仍可接管。
- `play_heading=null`：回放也随机采样；改成具体弧度值可固定回放目标航向。
- `velocity_limits`、`smoothing_s` 保留作基础状态归一化和兼容速度槽配置，不再采样侧向或偏航角速度，也不再用于三轴跟踪奖励。

查看器在蛇头上方显示橙色指令箭头和绿色当前蛇头朝向箭头。橙色箭头方向表示目标航向，长度随前行速度指令线性变化：达到 `forward_speed_cap` 时长 0.2 m，半速时长 0.1 m，零速时隐藏；短箭头同时按长度缩细，避免低速时箭头头部尺寸超过箭身而显示畸形；绿色朝向箭头保持固定长度。初始身体仍朝 +X，箭头指向的目标可不同。

`env.actions.joint_pos` 中，`target_limit`、`snake_target_limit` 均为 `2.0943951023931953` rad（±120°），`max_target_speed` 为 `6.283185307179586` rad/s（360°/s）。调整角度范围时同步修改两个 limit 字段。它们约束控制目标；XML 机械关节范围仍为 ±6.28 rad，没有新增实际关节速度硬限位。

实际运动箭头直接读取蛇头 `foot_0_sole` site：青色箭头绘制世界 XY 水平线速度，方向为实际运动方向，`forward_speed_cap` 对应 0.2 m 箭头；紫色竖直箭头绘制世界 Z 轴偏航角速度 wz，向上为正、向下为负，1 rad/s 对应 0.1 m。零值隐藏，短箭头同步变细。不会绘制竖直线速度或滚转、俯仰角速度。箭头默认只显示当前选中的机器人。

## 回放键盘：前行速度与航向

原生查看器仅控制两个指令量：**非负前行速度**与**世界目标航向角**。速度与航向各自独立，键盘不设置侧移速度或偏航角速度。

| 按键 | 作用 |
|---|---|
| W / S | 前行速度每次增加 / 减少 0.025 m/s，限制在 0～`forward_speed_cap`（默认 0.2）；S 不倒退 |
| A / D | 世界目标航向每次增加 / 减少 10°，跨 ±180° 自动折回；保持前行速度 |
| Q / E | 与 A / D 相同，调整目标航向 |
| X | 前行速度清零，保留航向目标 |
| ↑ / ↓ | 与 W / S 相同，增减前行速度，不倒退 |
| ← / → | 与 A / D 相同，增减目标航向 10° |
| 小键盘 8 / 2 | 与 W / S 相同，增减前行速度 |
| 小键盘 4 / 6、7 / 9 | 与 A / D、Q / E 相同，调整目标航向 |
| 小键盘 5 或 0 | 与 X 相同，仅清零前行速度 |
| 逗号 / 句号 | 切换当前选中的机器人 |
| Enter | 复位并恢复自动航向采样 |

任一运动键接管当前选中的机器人，暂停它的自动采样；其他机器人继续独立采样。按键不重置身体姿态。屏幕显示目标航向、航向误差、前行速度指令、蛇头 site 实际速度和 AUTO/MANUAL 状态。橙色箭头的方向表示目标航向、长度表示前行速度指令（零速隐藏），绿色固定长度箭头表示当前蛇头朝向。
