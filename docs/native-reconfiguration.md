# 原生接触重构实验

这是独立实验入口，不替换已有训练或规划结果。复用现有
`robotics-mjbatch-py313` 环境，实际物理步进使用 MuJoCo，短时动力学响应
使用 CPU 上的 `mjbatch.Batch`；不依赖 MJLab，也不创建或下载环境。

```bash
./run_native_reconfiguration.sh
```

默认没有总模拟时长上限，各运动阶段也不因阶段超时而失败；可通过
`--duration-s` 显式限制一次试跑。Ctrl-C 会保存已记录轨迹和报告。
若控制器停滞，运行可能持续，逐步轨迹记录也会持续占用内存。
可通过 `--joint-target-speed` 调整实验关节目标速度，或通过
`--contact-force-n` 改变每接触点假设的原生黏附容量；后者默认为 35 N，
改变它只用于敏感性试验，并不代表磁铁的实测力。

查看最近一次执行的实际状态：

```bash
./view_native_reconfiguration.sh
```

要单独放大检查当前模型的连接面实体，可运行
`./view_native_connector_geometry.sh`；这是静态展开预览，不执行动力学。
使用 `--face 1` 到 `--face 6` 选择接口，`--gap-mm` 调整展开距离。

按空格暂停或继续，按 R 重播；可加 `--loop` 循环、`--speed 0.5` 慢放，
或 `--result 路径` 选择带记录的执行报告。运行时保存每 1 ms 状态和当次
MuJoCo 编译模型，回放只恢复保存的状态，不重新执行控制器；失败与超时的
执行也可回放。历史 JSON 如果没有对应轨迹和模型，不能据汇总重建原轨迹，
需要按原参数重新执行后才能观看新的试跑。

结果输出到 `outputs/reconfiguration/native_fsm/result.json`，可通过
`--output 路径` 修改。退出码为 0 表示状态机通过其成功条件；失败或到达
时间上限时退出码为 1。查看文件中的 `failure`、`events` 和 `safety_audit`
了解实际阶段、首次违规和审计范围。必须以实际报告判断结果，不应仅凭
代码包含全部阶段就认为全流程已通过。

场景仅开启新连接面圆盘、销钉、销孔，以及产生被动黏附所需的磁代理碰撞；
地面碰撞保留。模块原有本体碰撞关闭，因此本体不会与其他本体或地面碰撞。
该设置按用户要求执行，审计不能证明被关闭碰撞的部分安全。

磁代理采用 MuJoCo 原生被动 geom adhesion；每个接口四对磁铁均匀分布，
磁铁中心距连接面圆心 37 mm；按四对均分接口 140 N 的总拉力，默认每个
代理接触点容量 35 N，作用范围 3 mm。这是恒定接触容量近似，并非完整的
磁铁力—间距曲线，也不能保证不同姿态下的实际接口净拉脱力恰好为 140 N。
四个定位销高 4 mm，截锥侧面与轴线夹角 15°；沿用先前假设的 4 mm 销根直径，
尖端直径约 1.856 mm。方孔仍是 2 mm 厚的通孔板，因此销尖伸出孔板背面约
2 mm；本体外壳碰撞关闭，背面接触没有模拟。控制使用 Kp=15、Kd=1.5，1 ms 物理步和逐步
检查。实体和地面的接触由 MuJoCo 求解，侵入深度仅作诊断，不因侵入
重置或中止；不额外按法向深度拦截。检查仅覆盖离散步的原生接触，无法
检测已关闭的碰撞对；不能用它代替硬件安全验证。

接近控制使用 MuJoCo 点速度雅可比，结合批量物理预测，包括浮动模块
速度；释放阶段以短时物理预测估算接口载荷对六个伺服目标的雅可比，
搜索增大目标面载荷并抑制其他面载荷变化的方向。载荷包含求解器接触力
及磁代理被动黏附力；它是局部近似，不能保证分离或其他面安全。预测
轨迹本身未逐步审计，不是已经验证的全程 MPC。真实执行状态逐步检查；
失败应视为该次尝试失败，而非通过或全局不可行的证明。

首尾释放还会从当前状态并行筛选关节目标轨迹，并用载荷雅可比排序；
候选在实际执行前用复制的MuJoCo状态逐1 ms重放，检查非目标磁连接、
电机及仿真异常。预测通过不保证真实执行一定通过，执行过程仍独立检查。

最终接近先粗对齐横向及姿态并建立约15 mm轴向预留距离，之后沿目标接口
局部Z轴靠近，同时持续修正横向和姿态。锥销、方孔及磁代理的接触由
MuJoCo自然求解，近场不再因固定横向或角度阈值中止；距目标10 mm内
逐1 ms记录实际推进时的横向及角度偏差，每步推进小于10 nm的变化不计入。
这不保证实际运动严格沿轴线，也不能证明步间安全。当前完整流程仍未跑通。

配准，卷曲使用该分支对应的30 mm轴向预对齐关节目标；磁吸模型使用自己的物理与反馈控制，
参考分支不保证当前模型能够成功捕获。旧轨迹记录仍保留原来的配准。
