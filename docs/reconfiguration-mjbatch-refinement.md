# 首尾90°正逆向并行精修

本实验在当前MuJoCo 3.11环境中直接使用本机`~/Github/mjbatch/src/mjbatch/csrc/threadpool.h`的原生持久线程池，实现每线程独立`mjData`的多步候选动力学回放；不是安装或调用mjbatch Python `Batch`包，也不是在线MPC。该包依赖MuJoCo 3.14，不能直接覆盖共享环境。原始线程池属于Apache-2.0上游项目；本项目C++桥接负责逐物理步读取各有效weld反力、力矩、碰撞和电机约束，独立状态恢复及候选结果归约。

固定初态、1ms物理步、目标面100N被动断裂；优化和实时监测中其他有效连接面的等效载荷上限80N（目标加载阶段排除当前目标）。物理真实载荷可能在1ms内跨过上限，保护在采样后停止，不能保证此前任意连续时刻或不同条件下始终不越过80N；此模型、控制、阈值亦未实物标定。关节限位仍按用户要求忽略。

## 执行

```bash
./scripts/python.sh scripts/view_headtail_mjbatch_refined.py
```

与双向查看器相同，1、2分别从当前兼容直链状态启动正/逆向，Enter重置当前方向，同一窗口不重建；还可加`--headless --direction forward`或`--headless --direction reverse`。正向展开执行离线筛选出的关节位置控制参考，仍用真实动力学和逐1ms保护；参考来自固定初态，当前未声称对其他姿态泛化。逆向独立重置初态及正向结束后连续逆向使用各自经过验证的卷曲速度。原`run.sh`及其他查看器保持原样。

## 候选与验证

- 前向卷曲使用状态机闭合终点，批量模拟不同速度，筛选20%裕度，并用完整FSM筛查。当前速度倍率12。
- 从完整FSM的展开起始状态记录真实位置控制参考和integration state；1024个候选由参考时间缩放及六关节平滑小偏移组成，通过8线程并行积分，每步检查非目标面80N上限、关节力矩及碰撞；筛出满足末端关节位置/速度要求的最快候选。不是全局最优，也不是当前状态实时滚动优化。
- 针对精修后真实正向终态，512个不同逆向卷曲速度多步并行评估，逐物理步筛选80N上限；最终逆向首段倍率1.3183953033。完整正逆向验证额外保留动力学重连、力矩、捕获、碰撞及80N保护。
- 固定初态连续正向→逆向→正向在单次完整试验中全部DONE，分别12.52/22.92/12.50s，非目标面最高79.222/78.705/75.212N，实际阈值裕度20.778/21.295/24.788N。首个正向和逆向对接最大间距分别0.899/0.916mm，姿态最大0.316°/0.511°。逆向独立重置初态为23.08s、79.809N。两方向运行间位置和速度逐元素保持，仿真时间连续。具体报告`outputs/reconfiguration/mjbatch_refinement/refined_cycle_test.json`。
- 1024展开候选并行评估一次12.14秒；同批256候选1线程24.54秒、8线程3.17秒，全部候选的状态码、峰值指标及末态关节最大值一致；另一个候选的完整integration state与串行MuJoCo逐项一致。测试期间存在其他CPU任务，耗时并非严格独占基准；不代表在线MPC频率。仅并行评估计时，不含生成控制、模型及复制开销。
- 扰动试验曾发现部分不满足80N，用户随后明确暂不考虑扰动；此方案仅声明固定初态测试结果。1024候选是同一展开初态的轨迹搜索，不是1024个扰动初态验证。

## 逆向首段稳定性修正（2026-10-29，覆盖上述逆向数值）

- 原逆向使用临时90°首尾注册；从精修后的正向终态开始，基座围绕初始直链轴的最大扭转约179.86°，模块最大角速度4.42rad/s，第3面峰值78.71N。翻转瞬态与载荷波动同时存在，但单次观测不能单独证明因果。
- 对混合角闭环分别搜索90°和270°注册角的静态解，并用mjbatch上游线程池分别并行筛选带速度与平滑关节偏移的多步动力学候选。当前选择逆向临时首尾270°、闭环另一分支（其后首尾仍被动断开），并用速度倍率约2.845和六关节平滑修正；内部重构参考速度乘0.7、加速度乘0.49，最终展开增益6、速度上限4.8rad/s、4秒渐进。正向仍用原90°临时注册；逆向后再按1从真实当前状态启动，内部运动速度乘0.8、加速度乘0.64以通过80N保护。
- 实际完整正向→逆向→正向验证分别12.52s/22.06s/13.66s，各非目标面峰值79.222/76.838/78.063N，1ms采样阈值裕度均≥20%。逆向首段10.34→3.84s，初始链轴基座最大扭转179.86→53.09°、模块最大角速度4.42→2.60rad/s，首段峰值载荷67.68N。53°仍有倾斜，不是零姿态变化；指标为相对初始链轴的扭转角，不是全机器人绝对姿态保证。逆向最大捕获误差0.894mm/0.383°，模块最大穿透0.968mm；忽略关节限位。逆向独立重置也完成22.14s。原末段较快配置第3面超过80N，因此未采用。
- 仅固定初态及连续确定性验证，未验证扰动、实机或任意状态下安全。证据`outputs/reconfiguration/mjbatch_refinement/reverse_stability/rotation_verified.json`和`final_cycle.log`。旧实验结果作为历史保留。

## 逆向末段加速及允许弯曲终态（2026-10-29）

- 用户指出逆向末段慢，并允许终态不完全直线。记录实际逆向展开控制和起始integration state，基于mjbatch线程池对1024条时间缩放/平滑偏移候选做1ms多步并行筛选；又把候选结束状态批量用于后续正向保持及卷曲筛选。最终选择第310号候选，而非只看逆向最快的候选，因部分更快的终态在下一次正向触发80N保护。
- `view_headtail_mjbatch_refined.py`的逆向从当前正向终态启动时使用已验证的加速展开参考；逆向独立重置仍使用原闭环展开控制。逆向关节最大绝对角降到0.15rad以下时固定当前目标保持，稳定后允许结束；保留拓扑、速度、间距和最大0.04m直线偏离检查。正向可从该近直链的真实状态继续，位置/速度/时间不重置。0.15rad约8.6°为本次试验的允许值，非实机标定。
- 固定初态完整连续正向→逆向→正向→逆向一次通过，耗时12.52/17.58/13.46/17.64s，非目标载荷峰值79.222/76.838/75.380/77.277N，1ms采样均≤80N。两次逆向展开均1.88s（原6.36s），终态最大关节角0.1480/0.1489rad，模块中心最大直线偏离1.50mm左右。逆向独立重置20%裕度下完成21.16s。检查点报告 `outputs/reconfiguration/mjbatch_refinement/reverse_fast/repeated_cycle.json`；候选及筛选见同目录。
- 这次仍是已保存参考、固定初态和两次确定性往返；终态存在小幅弯曲，不证明任意构型、扰动或实机均满足裕度。1ms超限监测是采样后停止，不是连续时间不可跨越80N的保证。

## 2ms物理步长独立实验（2026-10-29）

用户将本实验目标改为2ms跑通，允许放慢且不再强制20%裕度；连接100N被动断裂、力矩与非有限/接触保护仍启用。独立入口：

```bash
./scripts/python.sh scripts/view_headtail_mjbatch_2ms.py
```

物理2ms、控制20ms；正向与逆向内部轨迹速度各减半、加速度乘0.25，卷曲速度分别乘原方案0.5/0.7，位置PD刚度100、外段40，阻尼维持4。目标分离规划间距2.6cm，实际阶段转换仍要求至少2cm和原净空；采用现场最近点控制展开，不重放1ms离线加速控制。连续逆向加载模型目标留量15N，仅用于求解，实际目标/非目标断裂阈值仍100N，仍先做复制状态预演。模式1/2不重置，回车重置；1ms入口与其80N保护保持。

实际固定初态连续正向→逆向→正向→逆向两次往返均完成：26.68/35.36/29.02/35.86秒，非目标面最高52.80/97.06/71.74/97.27N。五次捕获最大间距各0.887/0.939/0.887/0.948mm，角度0.860/0.386/0.878/0.386°；最大地面穿透2.55mm，接触保护为3mm。逐步检查没有非有限/电机违规，不能将单一初态两次往返当作普遍数值稳定、无碰撞或实机保证。逆向峰值接近100N，此实验不满足先前20%裕度；用户已明确允许。证据 `outputs/reconfiguration/mjbatch_refinement/timestep_2ms_free_margin/cycle_100kp_gap26.json`。逆向独立初态也跑通；6项相关测试、编译和窗口启动冒烟通过。
