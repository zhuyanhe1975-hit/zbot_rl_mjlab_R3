## 使用边界

卡片保存后，下次启动训练/回放读取新值；已创建的环境和注册配置不热更新。主动调参导致配置契约变化时，应核实预期差异后有意识更新基线。

卡片控制配置字段和既有奖励函数参数，算法内部EMA、阶段阈值等仍在实现模块。结构/类型/有限数值校验不等于完整的超参数范围验证。改变网络/控制接口需要匹配检查点或重新训练；本次仿真和配置对照不证明收敛、全向控制达标或实机效果。全仓Pyright仍有既有诊断，不能视为通过。
