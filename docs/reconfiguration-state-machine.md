# 独立重构状态机

暂停学习期间使用此入口，不创建PPO、网络、优化器或读取检查点。

```bash
bash run.sh
bash run.sh --headless --output outputs/reconfiguration/state_machine/manual.json
```

默认打开MJLab原生查看器；无窗口模式执行完整的一轮并写JSON，成功退出码0，失败或未完成返回1。`--num-envs`支持多个环境，独立记录每个环境第一轮结果。可视化模式完成后自动复位，继续演示；Enter可手动复位。

流程为：施加加载力矩 → 真实载荷解除目标weld → 端口距离拉开超过5cm → 保持分离间隙并绕连接面法向相对旋转+90度 → 保持新注册姿态并缓慢接近 → 满足几何和速度门槛后重建weld → 稳定保持2秒 → 完成。5cm后的旧训练终止流程在这个独立入口中被后续旋转与对接替代，原训练实验保留。

目标面固定为首尾面5，其他五面始终保持连接。旋转以另一端连接面坐标系的+Z为正轴，目标是相对初始注册角+90度。模型预先增加一个旋转−90度的端口site及对应初始禁用weld，新姿态贴合后启用这个weld，原始目标weld保持禁用。既不改qpos/根位姿，也不把错位姿态直接固化为约束参考。

加载复用约束J/M/R前馈。拉开复用距离雅可比；旋转和接近采用六维相对位姿阻尼雅可比控制。执行器始终为MJLab自带BuiltinPositionActuatorCfg，目标角由关节速度积分。分开、旋转、接近各自最多1秒，满足真实几何条件后可提前进入下一段。距离速度上限.15m/s、位姿控制线速度上限.15m/s、旋转角速度上限6rad/s；关节目标速度上限6rad/s、加速度上限30rad/s²。这些是上限，实际由雅可比、误差和速度反馈决定。独立状态机允许最大.5rad目标跟踪误差，原训练实验的.05rad设置不变。力矩保护、其他面安全阈值保持。

重建门槛：端口距离<2mm、相对新注册姿态角误差<2度、相对线速度<.03m/s、相对角速度<.3rad/s，连续保持.03秒。激活新weld后，用.2秒把其solref时间常数从.03平滑收紧到原.005，避免毫米级对接误差瞬间产生冲击；原五面约束不变。达到完整约束强度后再稳定观察2秒，仍逐物理子步检查weld载荷、其他五面安全和电机限额。任一安全失败或阶段超时进入FAILED，不继续强行贴合。

运行报告保存阶段、距离、姿态误差、关节角、目标角误差、速度、六面载荷和新weld状态。失败码1表示物理安全/断裂/力矩失败，2表示一般阶段超时，3表示分开/旋转/接近超过各自1秒期限；失败后停止运动，仅保留阻尼，不按计时器强行宣称完成。局部雅可比控制不是全局避碰规划，旋转完成要求相对90度目标误差<1度、端口间距≥5cm、相对角速度<.5rad/s；不要求此时已经满足精确贴合位置，贴合由接近阶段完成。具体验证结果以项目记忆为准。


当前验证：固定IK初态、16环境真实GPU完整执行16/16成功。分开约.500–.515秒、旋转约.665–.880秒、接近并激活新weld约.610–.910秒，后续收紧及稳定观察约2.2秒。参考`outputs/reconfiguration/state_machine/verification.json`，其中保存最终入口复测、配置、阶段时长及每个环境的终态。测试覆盖原生PD、各段期限、六面载荷保护、新注册角约束重建、完成后复位和超时不强行重连。上述结果不代表随机初态或不同目标面的泛化。
