## 旧成功双足策略的受控回放

使用同一份 `bests/omni_velocity_energy_2026-10-10_iter499/model_499.pt`，在当前独立双足场景中固定`.5Hz`、请求`.15m/s`，每种限制运行6秒，比较最后3秒：

| 动作处理 | 目标角偏移范围 | 实际平均前向速度 | 跌倒帧比例 |
| --- | --- | ---: | ---: |
| 原Gaussian均值动作 | 未额外截断 | .13933m/s | 0 |
| 原动作裁剪至±1再乘.25 | ±.25rad | -.00019m/s | 0 |
| 原动作裁剪至±1.5再乘.25 | ±.375rad | .13946m/s | 0 |

原成功策略约15.5%的动作分量超过±1，最大值约1.35。旧配置的`scale=.25`表示缩放系数，不能解释为目标角偏移只能±.25rad；Gaussian有无限尾部。将其移到有界Beta动作时，之前的适配丢掉了成功步态使用的范围。这是可复现的控制范围差异，不应通过增加网络或等待更多迭代掩盖。

此结果只证明限制±.25rad足以破坏这份成功策略在该测试条件下的步态；不能证明±.375rad的新Beta策略必然学会行走，更不能证明蛇爬已解决。后续对照仍需用户训练并验收。
