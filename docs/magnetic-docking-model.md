# 四磁铁接口：稳定仿真的建模边界

每个模块对接面有四个永磁铁。四点 site 是位置标记，既不是磁铁实体，也不会自动产生磁力。实际安装坐标、极性、间隙相关吸力和连接强度尚未标定；当前四点工具的 50 mm 半径只是用于验证几何的参数，不是实测尺寸。

用户补充：连接面上有高 2 mm 的销钉和销孔配合，连接时机械结构限制面内剪切滑移和绕对接面 Z 轴旋转；期望通过绕连接面 X/Y 轴的倾覆加载来克服磁吸并分离。此处的 2 mm 是销钉高度，不能直接当作中心 site 间距的脱销阈值：销的位置、孔的间隙、接触角和倾覆方向决定各销是否退出，甚至可能限制允许的倾覆角。轴向直接拉开在物理上是否可行取决于其他机构和驱动力，不能仅凭销孔限制 XY 与 Z 转动就判断其绝对不可能；规划采用倾覆策略与物理失效模型是否包含轴向拉脱是两个问题。

建议把接口区分为自由接近、磁吸接近、已连接和脱开后的状态：

1. 按实际极性和选定的 90° 方位配对，使用四点和 `mj_jacSite` 引导；在对接容差外，仍由已有几何安全检查拒绝非法接触。四点靠近本身不证明实体不碰撞。
2. 只有获得磁铁吸力随间距、横向偏移、姿态变化的数据后，才配置有界、平滑衰减的磁吸力及必要阻尼。所有作用力必须成对施加、守恒作用与反作用；尚无数据时不应伪称存在真实磁吸或填入任意力值。
3. 位姿、相对线速度和角速度满足捕获条件后，启用所选方位的 MuJoCo 原生 weld。锁定后的 weld 近似表示四对磁铁吸引与模块端面机械定位、接触共同形成的等效连接，可按实测柔度调整求解器参数；它并非磁场模型，也不会自动因超载而脱开。锁定不能通过直接改写位置或速度来消除跳变。若另外加入磁吸或端面接触，需核对其与 weld 承担的作用，避免对同一力学效果重复计入。
4. 根据试验标定的连接面合力和力矩失效包络判断脱开，包括拉开、倾覆及必要的剪切/扭转；断开后的吸力和滞回也需标定。分离、重新连接要有合理的状态切换条件，避免阈值附近反复切换。

现有全流程使用近似剥离指标 `max(Fz, 0) + sqrt(Mx² + My²) / 0.05`，目标接口 100 N 被动断开，非目标接口以 80 N 保护；这是原来的等效规则，不是四个磁铁各自的实测力或完整失效包络。weld 给出的是维持连接所需的净约束合力、合力矩；平衡状态下，磁吸预载和端面压力可以互相抵消，不能直接从净反力读出预紧力。对于超静定的四点接触，不能仅凭总合力和力矩唯一反推出各磁铁受力。接触反力、磁吸预载和定位结构承担的力也应在建模时区分。

需要的标定数据：四点相对各模块的实际坐标及极性；各可配对方位；销钉及销孔的数量、位置、直径、孔深、间隙和材料；拉脱力、剪切力、倾覆和扭转承载随间隙及速度变化；接触面刚度、阻尼和摩擦；定位结构的载荷作用；重复试验的离散度。单个标称吸力不能直接替代接口所有方向的失效阈值。weld 断开后如要模拟销孔物理，需有合适的销钉/孔壁碰撞几何和接触；仅凭四点 site 或单一非凸网格的凸包无法保证孔的形状得到保留。可使用经过验证的凸分解或其他合适碰撞表示。

验证应分层进行：静态不同方向加载和偏心剥离；不同间距与相对速度的吸合；连接和断开瞬间的动量、能量及数值稳定性；1 ms 与更小步长的对比；最后才是含碰撞与驱动限值的全流程仿真。纯软件结果不代表已通过实物验证。
