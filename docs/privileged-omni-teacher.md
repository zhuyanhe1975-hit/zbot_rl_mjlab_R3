## 当前纯双足对照

当前Wide任务默认`mode=stand`，训练与回放全部从规范双足姿态开始。训练只重新采样双足`vx/vy/wz`、混合速度和停车，绕过联合任务配额；重置、局部重置和定时采样都不会产生蛇形或站起／爬下任务。构型编码固定为`+1`，任务编码固定为`0`；56维布局、网络、PPO、奖励权重、动作范围、随机化和扰动设置均保留，以隔离混合任务的影响。蛇形／变形奖励仍保留定义，但其任务掩码不激活。

```bash
bash train.sh
bash run.sh
```

默认从头开始独立run `biped_scalar_only_v1`，回放只查找本次对照目录，不会自动选到此前联合训练的模型。回放16个均为双足，默认请求本地前向0.05m/s，键盘速度控制仍仅作用于选中机器人。仍保留手动变形控制能力，但本阶段不自动请求变形。旧基础Teacher任务和bests保持原配置。没有启动完整训练；训练由用户执行。

## 原联合目标（暂缓）

同一个策略从头联合学习双足和蛇形的前进/后退、左右侧移、左右原地转动、混合 `(vx,vy,wz)` 指令、停车，以及站起/爬下双向变形。所有运动指令类别从训练开始就参与，训练环境按双足运动40%、蛇运动40%、起立10%、下降10%分配（至少10环境）；指令幅度采用成功归档可学习的范围，扰动逐渐增大，但不分成单技能预训练阶段。

沿用已确认的 `foot_0_sole` 重力对齐坐标：双足前向为site局部+X在地面的投影，蛇形前向为site局部−Z投影；vy向左，wz绕世界+Z为正。坐标随site航向旋转，初始世界yaw随机。平移奖励测量整机COM速度，偏航测量site角速度。

W/S、A/D、Q/E分别调整vx、vy、wz；X停车，`[` 切蛇形，`]` 切双足。这些控制只作用于当前选中的机器人，`,` / `.` 切换选择；其他机器人的自动速度、构型和观测历史保持独立。键盘改目标保留物理状态，变形到位后恢复待执行的速度请求。

## 特权观测与算法

当前Wide任务Actor输入56维、无噪声、无历史的仿真真值：

| 部分 | 维数 | 内容 |
| --- | ---: | --- |
| 综合真值状态 | 50 | 真实关节位置/速度、积分目标/上一动作、site速度、基座IMU方向/角速度、基座高度、接触、构型1维与任务1维、平滑速度指令、步态时钟、相对航向、COM状态、归一化接触力 |
| COM跟踪速度 | 3 | site坐标系的整机质心平移与site偏航速度 |
| 原始速度请求 | 3 | 未平滑的vx/vy/wz，供策略提前响应 |

Actor/Critic都从同一份 `actor` 观测组读取56维输入，避免重复计算状态；网络各为256/128、ELU，开启观测归一化。策略为六关节Beta动作。v2中稳定双足运动采用默认站姿附近±0.25rad的有界位置偏移，按现有最大目标速度限制每步变化，避免变形结束时跳变；蛇形和变形仍积分为关节目标角。这是借鉴成功双足动作的混合控制适配，尚需完整训练验证。

v2双足使用归档完整的速度跟踪、抬脚、姿态、足底滑移/平行、落地冲击、限位、加速度、动作变化与能耗组合；步态频率每回合采样0.25–1Hz，蛇形使用0.7Hz。变形需接近目标关节并稳定2秒，双足完成高度至少0.24m；已站稳后的双足按0.22m/归档倾斜阈值判摔。匹配构型的规范初态直接进入运动，保留0.1秒接触传感器启动宽限。

本教师的蛇形稳定运动阶段（目标蛇形且已完成变形）六个关节目标角均限制为±60°（±π/3 rad）。饱和后直接保存裁剪结果，反向动作立即离开限位，不累积隐藏积分。双足和两个变形阶段保留原目标范围：站立姿态的部分关节约±115.7°，不能把全任务统一限制成±60°。该设置同时作用于训练和回放；不修改机械XML，实际角度仍可能因伺服跟踪短暂超调。重启训练或回放后加载新限制。

使用标准PPO运行器，无冻结教师加载、无旧walking/omni网络、无变形教师指导、无蒸馏预热或动作标签。教师自行学习变形，关闭部署学生的强制归直软件阶段。训练配方参考 `bests` 成功归档，具体来源、参数与适配边界见[成功归档参考](privileged-omni-bests-reference.md)。复用配置和奖励公式，不加载旧教师策略。

PPO学习率初值为 `3e-4`、熵系数 `0.005`、每轮5个epoch/4个mini-batch，采用adaptive KL调节。变形奖励按归档最终有效权重设置，仅在变形阶段生效；双足稳定运动的足底代价、全局归一化能耗也复用成功定义。随机化保留足部摩擦和基座COM；暂不叠加额外质量/PD增益随机化。外扰从0开始，在500轮内渐增到受扰行走归档幅度。

这些特权输入包含实机通常无法直接获得的状态；此策略作为后续蒸馏源，不能直接当作185维部署学生播放或完整续训。

## 训练与验收

默认8192环境、6000轮、每轮24控制步、每50轮保存检查点。默认关闭周期验收，不在100/500轮创建额外环境或输出阶段汇总。

独立验收为20场景：两种模式各自的停车、6个正负单轴、2个混合指令，以及起立和爬下。每场景覆盖0/90/180/270度初始世界yaw，包含中途真实命令API改目标。验收要求持续跟踪、构型到位、有限状态及双足不跌倒。终端汇总 `biped x/9 snake x/9 transform x/2`，每项和每个初始yaw的完整记录写入TensorBoard。

由用户启动完整训练：

```bash
bash train.sh
```

等价显式命令：

```bash
./scripts/python.sh train.py Mjlab-Zbot-6dof-Universal-Snake-Leg-Omni-Teacher-Wide-Biped \
  --env.scene.num-envs 8192 \
  --env.omni-frame-backend cuda_graph \
  --agent.max-iterations 6000 \
  --agent.run-name task_fsm_v1
```

`cuda_graph` 只捕获此前验证的纯张量site航向计算，标准PPO、重置、课程和日志仍正常执行。可用 `--env.omni-frame-backend eager` 切回原实现。需要完整终端输出时使用 `--agent.console-mode full`。

教师检查点的 `infos.privileged_omni_teacher` 记录角色、观测/动作维度、schema版本和已完成的PPO更新数，另存速度课程。当前Wide的标量编码使用56维schema3；原59维保留schema2，回放按检查点自动选择。v2恢复归档的256/128网络并改变动作语义，schema升至2；请使用新run，旧v1检查点不能作为v2的完整续训或同语义回放。完整恢复先校验角色/维度/课程，再加载权重与优化器；拒绝误载旧学生或其他实验的完整状态。若修改59维字段顺序/含义，应同时更新schema版本。续训从已完成更新数之后继续，避免重复保存的零起始循环索引。

```bash
./scripts/python.sh train.py Mjlab-Zbot-6dof-Universal-Snake-Leg-Omni-Teacher-Wide-Biped \
  --agent.resume True \
  --agent.load-run <本教师的运行目录名> \
  --agent.load-checkpoint model_<迭代>.pt \
  --agent.max-iterations <本次额外训练轮数>
```

回放教师仍使用同一特权观测任务：

此前联合配置（`mode=source`）回放随机分配双足和蛇形初态；当前默认纯双足，以下描述仅供联合配置恢复时参考：16个环境为8个双足、8个蛇形，编号顺序随机；单环境回放随机选择一种。各环境目标与初态匹配，并自动请求本地前向0.05m/s：双足走、蛇形爬，到位后平滑起步。回放不自动切换构型，也不会因失稳自动进入变形恢复；关闭自动回合复位，避免超时或跌倒后重新随机分配构型。只有当前选中机器人收到 `[` / `]` 键盘指令时才执行构型切换，其他机器人继续原构型运动。键盘随时接管，X停车后保持停止，构型切换保留当前速度请求。显式Enter复位仍可重新初始化。可通过命令配置 `play_velocity` 调整默认三轴请求，设为全零即可启动后等待键盘。需要固定构型时可加 `--env.commands.transform.mode stand` 或 `snake`。此规则只作用于教师回放，训练初态与目标仍按原有分布采样。

```bash
./scripts/python.sh play.py Mjlab-Zbot-6dof-Universal-Snake-Leg-Omni-Teacher-Wide-Biped \
  --checkpoint-file <教师检查点> --env.scene.num-envs 1
```

短程验证中未训练策略未通过完整技能验收，这是正常结果。是否掌握全部技能须由用户运行完整训练后，以独立闭环验收为准。

## 回放跟踪相机

原生mjlab viewer用 `\` 开关所选机器人的相机跟随。XY注视位置默认使用0.2秒时间常数的指数低通，按实际渲染间隔更新，减少步态/伺服抖动；鼠标设置的高度、方位、俯仰和距离保留。

`play.py` 可加 `--follow-smoothing-time 0.4` 增强平滑（跟踪滞后也增大）；设为 `0` 恢复直接跟随。只影响原生回放viewer，训练、物理和策略不受影响。

第300轮不动的实测证据、v3采样修复与扩网对照命令见[停滞诊断](omni-v2-stall-diagnosis.md)。网络默认仍为256/128，便于先验证采样修复。

当前构型和任务由[显式状态机](omni-task-fsm.md)驱动，接触瞬断不会切换任务。统一使用`bash train.sh`与`bash run.sh`。

当前仅Wide任务的[构型1维、任务1维观测与旧检查点兼容说明](scalar-observation-update.md)。基础Teacher及旧bests任务保持原观测。
