本次审查覆盖 `bests` 中单独双足全向、受扰/部署行走、蛇爬、特权起立与双向变形的配置、最终有效奖励和已有验收记录。代码复用其训练机制，不加载旧教师策略。学生仍暂缓；没有启动完整训练。

## 第300轮的实际问题

运行 `2026-10-20_09-11-56_privileged_omni_v1` 的TensorBoard记录：

| 指标 | 第100轮附近 | 第300轮附近 |

| 起立阶段占比 | 46.4% | 47.7% |
| 双足8个移动场景通过数 | 0 | 0 |

这是实际未学会移动，不能用“联合任务更难”替代诊断。这些阶段占比为回合日志统计，不是严格按所有仿真帧重新加权的全局比例。v1速度奖励持续为负；学习率虽从`3e-4`启动，adaptive PPO曾自动提高到`0.01`，因此初始学习率也不能当作整个训练过程的有效学习率。

已证实的配置差异包括：旧双足动作围绕站姿直接给位置，v1为全范围积分；初始低速指令下v1跟踪核的半宽约`.01–.025m/s`，旧归档std为`.1m/s`；双足失稳长时间转成起立恢复；成功变形的到位保持、端关节范围和失败回收未完整继承。它们是有证据的风险机制，尚无消融实验可断言各自造成多少性能下降。

## 完整奖励组合及单位

双足运动逐项核对 `omni_velocity_energy_2026-10-10_iter499/env.yaml`，没有只保留其中的惩罚项：

| 项 | 权重/参数 | 生效范围及适配 |
| --- | --- | --- |
| vx/vy/wz跟踪 | `2/1/1`，std`.1/.1/.25` | 稳定双足；换为已确认的site坐标及COM测量 |
| upright | `+.2` | 稳定双足 |
| swing_clearance | `+.5`，目标`.05m`，核宽`.04m` | 稳定双足且有运动请求；停车不强迫抬脚 |
| support_foot_slip | `-5` | 稳定双足 |
| soft_landing | `-.02` | 首次接触的峰值力，单位N；恢复接触计时与4子步历史 |
| foot_nonparallel_ground | `-5`，std`.1` | 稳定双足 |
| action_rate | `-.05` | 双足动作差平方和；其他阶段`-.01` |
| joint_limits | `-.1` | 稳定双足，真实关节限位越界代价 |
| joint_acceleration | `-.0001` | 稳定双足，绝对加速度之和，未误改为平方和 |
| joint_energy | `-.5`，scale10 | `clamp(sum(abs(tau*qdot))/10,max=1)`；稳定蛇运动的探索缩放见下 |

摆脚高度扫描复用已有walking配置中修正后的sole-site坐标；归档旧body原点扫描有足部原点偏移问题，不盲目复制。接触力历史和高度扫描会增加采样计算量，这是恢复训练信息的明确成本；本次没有给出8192环境的速度增益承诺。

蛇爬对照 `snake_world_x_2026-10-19_iter1499`：

- 推进`15×有符号COM速度`，封顶于`min(指令速度,.2)`；世界X改为site坐标中平移指令的方向，因此支持反向/侧移/混合。
- 横向滑移`-5×abs(v_perp)`，乘`clamp(.25+5×正向推进速度,max=1)`；低速探索时少惩罚。
- COM竖直速度绝对值`-.2`、相对蛇形零角的均方偏差`-.02`、限位附近目标比例`-.1`。不能误用通用场景的站立默认角作为蛇形参考。
- 纯转向单独跟踪yaw，停车不领取推进基线。全向yaw跟踪及把探索倍率用于能耗，是当前任务适配；归档没有证明这套混合目标有效。
- 不移植固定世界X、固定初始航向终止、全局三维镜像。这些会禁止用户需要的侧移/转向。蛇头/自碰撞等额外专用安全规则尚未完整移植，需要新增传感器及全向允许范围验证；不能假称已经等价复刻。

变形对照双向归档最终有效权重：姿态12、高度1、上升8、足底1、失败-10、完成关节速度-.02、下降撞击-2。与回合YAML的初始权重区分；上升峰值、失败计时都独立管理，避免旧任务状态污染。三维镜像搜索空间没有直接移植，六维起立的学习难度仍是风险。

## 检查与运行边界

归档YAML只在测试中用BaseLoader读取，不执行Python标签。测试覆盖参数来源、公式与单位、技能/阶段门控、同一时钟、早期失败计时和部分重置、动作不累积与阶段连续衔接；GPU只做少量环境步，未进行本轮策略训练。

v2的完整技能效果需要用户新run训练并验收，不能用单元测试通过宣称已学会走路。既有v1进程不会因修改文件自动变成v2；本次没有停止或修改用户训练进程。

本轮验证：`pytest tests -q`为2024项通过；涉及的训练代码与新增测试Ruff/Pyright通过。GPU分别运行16个训练配置环境和16个回放配置环境，各30个零动作物理步，59维观测与奖励均为有限值；回放最终阶段为8双足运动/8蛇形运动。未进行策略优化，不能由此推断学习速度。
