# 人工流程、运动学与 mjbatch 筛选

在项目根目录执行：

```bash
./run_planned_mjbatch.sh
./run_planned_mjbatch.sh --threads 16 --candidates 41
```

脚本针对精修查看器的固定初态，完成以下步骤：

1. 沿用人工编排的正向状态机：首尾闭合、按 1→2→4→5 顺序重构内部接口、释放首尾、展开与稳定。
2. 以保存的 90° 分支作为初值重新求解闭环运动学，用 MuJoCo 静态检查连接位姿误差。
3. 用 mjbatch 仓库的 C++ ThreadPool 并行模拟不同首尾卷曲速度，并进行原生 MuJoCo 串行核对。筛选范围默认为速度倍率 10～12；`--min-speed`、`--max-speed`、`--candidates` 可调整，线程默认为进程可用 CPU 核心数。
4. 将通过首尾阶段筛选的候选按耗时排序，实际执行整个状态机并检查是否完成；默认最多验证 3 个候选（`--max-validations`）。结果写到独立的 `outputs/reconfiguration/planned_runs/时间戳/`，包括运动学解、批量筛选、完整验证和 `result.json`。已有结果不会被覆盖。

实现依赖 `~/Github/mjbatch` 的线程池和 MuJoCo 3.11 原生桥接；缺少桥接库时自动编译。它并非 Python 的 `mjbatch.Batch`，并沿用精修查看器及 MJLab 环境，不是独立 mjbatch PPO。全流程的内部重构由已有状态机和运动学规划执行；展开阶段使用先前筛选的 `unfold_best_1024.npz`，本次并未重新筛选展开轨迹。完整仿真使用 1 ms 子步、80 N 非目标载荷保护，并保留原查看器碰撞过滤；没有验证首尾对齐前零碰撞。

当前新运行的位置伺服默认 Kp=15、Kd=1.5，批量筛选和完整状态机使用同一参数；加载阶段仍有原状态机的专用力矩控制。仍沿用有加速度参数的旧查看器轨迹，并非无加速度限制方案；旧 12.52 秒结果使用旧伺服。仅固定初态可验证，不代表扰动或实际机器人安全。

可视化最后一次 run 或 polish 执行的结果：

```bash
./view_planned_mjbatch.sh
./view_planned_mjbatch.sh --result outputs/reconfiguration/planned_runs/某次运行目录
./view_planned_mjbatch.sh --speed 0.5
```

窗口按 Enter 从初始状态重新播放，关闭窗口退出。脚本读取保存的关节解、卷曲速度和展开控制路径，然后重新运行物理仿真，并非回放逐帧录像；依赖当前模型和控制代码与原运行一致。`--headless` 可无窗口复跑验证。

新运行对接反馈在目标 site 坐标系中提高姿态权重：横向 XY 和姿态未对齐时软抑制 Z 法向修正，达到 1 mm / 2° 后再以完整权重接近。该反馈用于首尾捕获和内部接口接近轨迹结束后；预设接近轨迹及动力学耦合仍可能产生法向移动，不构成严格的先后顺序或无碰撞保证。旧结果按其保存的反馈版本回放。

新规划在首尾卷曲/捕获和内部接近阶段、site 间距离不超过 30 mm 时逐 1 ms 检查：目标 site 中 source 相对位置的负 Z 是正法向间距，间距小于零即判失败。此检查只覆盖这些阶段和邻域，不等同真实几何碰撞检测，也不保证子步连续安全。旧卷曲轨迹未通过该条件；默认可视化读取最后一次执行，失败或未完成时会报错；旧结果可用 `--result` 指定并会显示警告。

首尾候选可通过 `--offset-rad` 设置平滑关节路径扰动上限（默认 0.3 rad），先批量做动力学筛选，再逐个进行完整流程与法向检查；筛选通过不意味着完整验证通过。可用 `--candidates` 和 `--max-validations` 扩大搜索。当前固定初态已有候选通过限定阶段的法向检查；不能据此保证未检查阶段或连续时间无穿越。

当前入口会优先复核 `scripts/planned_curl_seed.json` 记录的候选，并把它与新候选一起做动力学批量筛选；然后执行完整验证。第4接口使用单独分离、旋转和提前反馈，等待上限为30秒。已有固定初态验证用时32.36秒；展开依然使用历史控制序列。`--offset-rad` 控制新随机候选，种子候选不受其限制。

第4接口现使用100ms动力学预测、有限差分雅可比进行XY及姿态优先修正；达到XY<1mm且角度<2°前法向软目标为10mm，达到后改为0.4mm；实际距离可能因惯性和动力学耦合波动。固定初态验证中对齐前法向间距最低约9.63mm，用户已确认该程度可接受；法向检测的范围和离散限制仍适用。
