# 六模块完整重构：原生MuJoCo CPU状态机

```bash
bash run.sh
# 或直接运行
./scripts/python.sh scripts/reconfigure_mixed_full_cpu.py --viewer
# 无窗口验证
./scripts/python.sh scripts/reconfigure_mixed_full_cpu.py --headless
```

该独立实验从全180°直线开链开始，卷曲并闭合首尾，按第1、2、4、5面依次重构到 `[270,270,180,90,90]`，最后被动断开首尾并展开为直线。第3内部连接全程保持原注册，所有开链阶段仍是六模块一条连通链。初始物理qpos/root仅在初始化写入，此后由动力学积分推进；关节限位遵照此前用户要求忽略。

## 动力学与控制

- 原生MuJoCo CPU动力学，1ms物理步、20ms状态机控制周期；使用MJLab配置生成的原生位置执行器。动力学与规划使用CPU，不依赖CUDA计算。
- 直线初态通过刚体方向调整使弯曲方向接近地面，所有模块共同支撑；初始约0.3mm地面接触穿透，属于软接触初始条件。卷曲使用较柔和的原生位置PD跟踪。
- 首尾初次闭合和各内部面重连：达到2mm、2°、速度和持续时间门槛后重建weld，0.2s软化过渡包含在总计1s的连接保持期内。
- 内部面使用约束雅可比与32候选方向计算安全力矩，被动达到80N才解除；断开后同一物理子步撤去加载并切换原生PD。分离、旋转、接近沿运动学引导样条执行，内部轨迹按5ms采样进行非匹配几何与旋转间隙预检。
- 最后首尾连接同样要求80N被动断开。加载前识别闭环近奇异方向；根据雅可比生成候选，并在8个CPU线程上用独立MuJoCo副本预测下一物理步。仅采用预测首尾≥80.5N、其余面≤62N的候选，再由真实动力学和1ms硬保护确认。若无单步候选，回退CPU并行50ms响应估计和增量搜索，最多等待40s。
- 末段展开每20ms并行预测13组50ms轨迹，选择朝零位前进且其他面载荷留有缓冲的原生PD目标；目标偏移初始最多0.008rad，2秒后经8秒渐增至0.024rad。最终要求关节角速度、角度、根坐标直线性与首尾距离满足条件，并再保持1s。
- 目标面≥80N触发被动断开；其他面>64N、请求或实际力矩>20Nm、14Nm以上连续1s及模块/地面穿透超限均进入失败并冻结窗口；未放松安全门槛。
- 配对端面在连接、分离和接近时豁免；旋转时仅开启当前目标的显式配对接触。非匹配几何仍参与碰撞与监测。窗口右上角显示六面实时/峰值载荷和连接状态。

## 验证范围

在固定初态下曾完成完整真实CPU动力学流程。首尾解除依照80N瞬时阈值执行，并不证明该载荷可以静态持续。实际接触采用软约束，地面仍会有亚毫米级穿透；扰动、不同初态和实机尚未验证。历史报告保留在 `outputs/reconfiguration/mixed_full_cpu/`，其中包含研究期间主动解除首尾的独立诊断，生产入口只使用80N被动断开。

## 首尾展开接触修正（2026-10-28）

首尾断开后的展开及最终保持阶段启用首尾端面实际接触；此前将这对几何排除，旧版无穿透结论不适用于首尾。实际完整CPU复测成功，其他面峰值56.07N，首尾软接触最大穿透0.359mm；仍有小幅软接触压入，不能称零穿透。尝试0.024rad快速展开在接触开启时失败，后续改为渐进加速，正式复测展开约13.90s仿真时间。
