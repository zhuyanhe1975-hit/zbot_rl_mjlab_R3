# 第300轮不动：指令与训练覆盖诊断

诊断对象：`2026-10-20_09-29-53_privileged_omni_v2_biped_recipe/model_300.pt`。本次读取TensorBoard/检查点并运行短程确定性回放，没有进行策略更新或完整训练。

## 已测到的行为

标称条件下16环境、各指令运行4秒，统计最后2秒。8个双足、8个蛇形都处于运动阶段，有效指令已平滑到目标；不是play仍在变形阶段导致不走。

| 前向请求 | 双足实际前向速度均值 | 蛇实际前向速度均值 |
| --- | ---: | ---: |
| .05 m/s | .01270 m/s | .000008 m/s |
| .15 m/s | .00019 m/s | .000208 m/s |

结果只描述这次短程标称回放，不能外推所有初态或当作稳健成功率。完整数据保存在 `outputs/diagnostics/omni_v2_model300_probe.json`。

300轮的课程成绩为约`[8.94e-30,5.61e-24]`，一直没有脱离最初20%速度幅度。每回合日志中双足运动约13.8%、蛇运动20.8%、起立63.3%；这些是回合统计，不能当作严格全局帧占比，但已表明有效运动训练量不足。

双足奖励使用归档std`.1/.1/.25`，实际初始平移请求却只有vx`.02–.05`、vy`.016–.04`。按原八类采样计算，完全静止平均约拿`3.81/4`的速度奖励。归档独立均匀采样vx`[-.3,.5]`、vy`[-.2,.2]`、wz`[-.5,.5]`时，静止只约`1.32/4`。复用奖励宽度却缩小指令分布，改变了运动的收益差。

## 本次限定修复：v3采样

本次保持v2网络、动作、PPO和奖励权重，修改训练采样与回收方式，以保留归因：

- 教师速度采样去掉EMA缩幅依赖。停车占1/8，六个正负单轴合计3/8，混合占1/2；双足混合范围直接对齐成功全向归档。蛇形范围为±`.25/.2/.8`，按其当前指令方向推进。
- 双足单轴请求取对应端点的40%–100%，避免再次集中于比奖励核宽度小很多的指令。教师公共限幅为`.5/.2/.8`，双足yaw采样仍遵守归档±`.5`。
- 至少10个环境时，固定约40%双足运动、40%蛇运动、10%起立、10%下降。运动环境从匹配构型开始；变形环境从相反构型开始，完成稳定保持后回收该次尝试。环境编号在部分重置后保持任务配额。
- 少于10环境的训练回退为混合随机任务；回放保持已有随机初态和键盘变形控制。

四类环境从第一轮起共同更新同一个PPO策略。新采样下，针对运动请求的静止双足跟踪分约`1.97/4`；这证明收益结构改变，不证明策略已经学会运动。旧部署学生、单独walking/snake实验的采样不改动。

入口仍为 `bash train.sh`，新run为`privileged_omni_v3_sampling_fix`。建议新run对比；v2网络/动作兼容不等于采样修复前后的训练设置相同。

## 网络规模应如何判断

按当前59维输入、Beta六动作及独立Actor/Critic实际构建并统计可训练参数：

| 隐藏层 | Actor参数 | Critic参数 | 合计 |
| --- | ---: | ---: | ---: |
| 256/128 | 49,804 | 48,385 | 98,189 |
| 256/256/128 | 115,596 | 114,177 | 229,773 |
| 512/256/128 | 196,492 | 195,073 | 391,565 |

多技能可以适度扩大容量，`256/256/128`约为当前2.34倍参数，是合理的后续对照。当前证据首先指向指令收益与任务覆盖，尚无证据证明98k参数是主要瓶颈，因此本次保留默认网络。增加网络是否提升稳定性或学习速度，需要同一采样配方下比较独立验收，计算开销也需实测。
