# 蛇形前向推进

任务注册名仍为 `Mjlab-Zbot-6dof-Snake-Omni-Teacher`，日志目录为 `logs/rsl_rl/zbot_snake_omni_teacher/`。当前训练不跟踪速度指令，只学习沿蛇形自身前向推进。

## 速度、构型奖励与头倾终止扣分

取所有刚体质量加权的质心速度，投影到蛇形前向、左向和向上轴，得到 `v=(vx,vy,vz)`，关节初始构型为 `q0`。复用 `motion_axes` 定义：由 `foot_0_sole` 的 Z 轴和重力确定水平前向、左向，向上与重力反向；转向后奖励方向随蛇旋转：

```text
reward_rate = vx - abs(vy) - abs(vz) - 0.01*mean((q-q0)²) - 0.1*target_saturation_fraction
step_reward = reward_rate * step_dt - 0.5 * head_tilt_terminated
```

| 配置项 | 原始值 | 权重 |
|---|---|---:|
| forward_speed | 带符号的蛇形前向 vx | +1 |
| lateral_speed_cost | 蛇形左右 abs(vy) | -1.0 |
| vertical_speed_cost | 蛇形上下 abs(vz) | -1.0 |
| joint_pose_deviation | 相对初始关节角的均方偏差 | -0.01 |
| target_saturation_fraction | 目标角距 ±90° 边界不超过 0.001 rad 的关节比例 | -0.1 |
| head_tilt_reset_cost | 头倾终止标记 / step_dt | -0.5 |

沿蛇形前向前进得分，倒退扣分。左右/上下使用绝对速度成本，正负方向对称，当前权重均为 -1.0。构型惩罚权重为 -0.01，q0为六关节零角。目标顶限惩罚按六关节比例持续计费：一个关节顶限的奖励率约为 -0.01667，六个均顶限为 -0.1；离开边界即停止该项扣分。

头倾达到60°时，终止帧额外一次性扣0.5。奖励函数读取本步终止管理器的head_tilt标记，并除以step_dt抵消奖励管理器的dt缩放，因此实际事件费用恒为-0.5；复位后下一步不重复扣，其他复位原因不收费。没有恢复连续头倾姿态成本，也没有额外的速度/yaw跟踪、能耗、动作变化或接触冲击成本。使用整机质心而非蛇头速度，避免内部摆动冒充推进。

## 保留的初态与复位

- 初态从 XML 直立立柱绕 foot_0 局部 Y 轴旋转 -90°，四元数为 `(√0.5,0,-√0.5,0)`。foot_0.Z 指向世界 -X，foot_0.X 指向世界 +Z；初始高度 0.0555 m，关节零角。
- 训练保留全周随机初始 yaw，play 使用默认航向。每次 reset 都重建上述基础构型。
- 蛇头相对世界向上的总倾角达到 60°立即复位；头部向上基准为局部 +X。绕世界重力轴的转动不单独触发头倾复位。
- 非有限状态、离开 15 m 工作区、极端接触冲击、真实自碰撞及 30 秒回合时限的复位设计保留。

动作仍为六维有界关节目标速度，经积分形成关节目标角：

```text
q_target = clip(q_target + clip(action,-1,1) * 2π * dt, -π/2, π/2)
```

目标积分状态直接保存裁剪后的值，反向动作可立即离开边界。PD、摩擦、机械关节范围和原有安全条件未因本次奖励调整而修改。

## 审视与物理对照证据

`outputs/snake-audit/` 保存了物理、奖励和性能对照结果及复现脚本。固定周期关节波已经能产生持续推进，说明机械模型不是完全无法移动。旧速度跟踪奖励曾给静止约 7.63、有效推进步态约 1.25，存在明显的反向激励。

历史平方Y/Z成本对照中，一条稳定步态10秒沿+X位移约0.397m，平均奖励+0.03281；这些分数不适用于当前配方。等权绝对值探针中，一些有效步态仍低于静止得分，随后训练平均回合缩短到约1.2秒，主要由头倾终止。零动作10秒不翻，而旧策略约1.78秒越过阈值，简单缩小动作反而更早失败，因此没有盲目降低动作速率或放宽reset。

`reset_diagnosis.json` 对旧策略的回放反事实比较显示：在首次翻倒之前，旧回报约+0.148；采用YZ权重-0.2和一次性头倾费-0.5后，回报约-0.200（gamma=.99折扣后约-0.030）。这验证了当前旧策略“冲一下就翻”的收益被扭转，不等于新策略已经学会稳定运动。

验收应看确定性策略在后半段是否保持沿蛇形前向推进和关节周期运动，同时统计 Y/Z 漂移及真实复位，不能只看总奖励上升。低速、有限候选的对照结果不是最终学习性能保证。
