# 连通链运动学重构实验

实验标识：`Zbot-Closed180-To-Snake-RZ270-Kinematic-v1`。当前`run.sh`运行此实验，原单面动力学状态机保留。

```bash
bash run.sh
bash run.sh --headless
# 指定内部连接处理顺序与显示采样密度：
bash run.sh --headless --order 0 2 4 1 3 --steps-per-phase 20
```

这里只做FK/IK。忽略关节限位，不计算或验证力矩、动力学、载荷、碰撞及电机速度可行性。窗口由MuJoCo原生查看器显示预先求出的运动学帧；空格暂停，Enter重播。没有学习、检查点或PPO。

**整体必须始终连通。** 重构期间最多打开环上的一处连接，剩余五处连接形成一条完整链。所有模块根位姿只由一个锚定根和六关节FK派生，不独立搬动模块或链段。每帧检查图连通性，拒绝两个断口造成的分体姿态。用户先前允许的提前打开首尾后再拆内部连接方案已撤回，不再提供这个运行模式。

完整状态定义：初始六面闭环 → 先重构首尾辅助连接90°并重新闭合 → 依次对五处内部连接执行断开、分开5cm、旋转90°、接近、重建weld → 确认五处内部连接均为270° → 最后打开首尾辅助连接 → 连通开链展开到六关节零位。分开/旋转/接近各使用1秒名义播放时间，不代表已验证实际关节速度或力矩可行性。

目标为原Snake-RZ270模型的五处固定安装变换：`Ry(-45°) Rz(180°)`在右侧乘`Rz(90°)`。这是安装注册角变化，不是电机直接转到270°。内部连接的坐标基准为CAD安装原点，补偿诊断端口约0.2mm的平面偏置，避免仅旋转site四元数造成终态平移误差。终态与`rz270_spec()`做独立FK比较；全局刚体位姿不强制等同蛇形任务的世界初始位置/朝向。

**目前完整IK路径尚未跑通。** 当前默认顺序的试运行已完成首尾辅助连接和内部面0，在内部面1贴合时未收敛，程序停在最后一个有效且连通的姿态，显示`IK_FAILED`，返回退出码1。状态机不跳过该阶段，不启用错位weld，不移动断开的模块凑终态。此实验已具备完整状态框架，后续需迭代连通条件下的重构顺序或IK路径。

报告默认写到`outputs/reconfiguration/kinematic_rz270/latest.json`，可通过`--output`修改。包含阶段、关节角、注册状态、所有帧的连通性、有效weld几何误差，以及终态目标匹配。`success=false`表示没有完成目标。`open_chain_verification.json`等分体演示报告已被用户否定，不能作为当前实验成功证据。
